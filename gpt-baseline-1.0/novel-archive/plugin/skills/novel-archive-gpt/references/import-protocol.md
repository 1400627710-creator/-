# 可确认的文本导入

生成UTF-8 JSON。字段名称由作者决定；不要为了格式新增小说事实。

单档案格式：
    {"format":"novel-archive-import","fields":[{"name":"作者指定字段","value":"作者原文或明确采纳的内容"}]}

多条技能、物品或事件：
    {"format":"novel-archive-import","rows":[{"values":{"作者指定字段":"作者提供内容"},"keywords":["作者提供关键词"]}]}

可选metadata只写已确定的信息：title、number、timeLabel为文字；timeOrder为有限数字或null；keywords为文字数组。缺失信息直接省略，不为凑字段填入示例。

前端按现有字段名称和别名匹配，未知名称可创建新字段。同名冲突、无标题段落需人工指定，或者明确选择不导入。已有值默认追加，作者选择替换才覆盖。预览及取消均不改变原档案。

整库备份不是本协议。编辑作者上传的备份时，保留所有未请求改动的类型、版本、内部ID和布局，先验证备份结构，再交回作者自行确认恢复。
