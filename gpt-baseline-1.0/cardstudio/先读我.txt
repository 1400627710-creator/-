卡递 · 统一卡片工作台｜本地版 1.0.3-local.1

开始使用
1. 将整个压缩包下载到电脑，右键选择“全部解压”。
2. 用 Microsoft Edge 或 Chrome 打开“卡递-本地版.html”。
3. 首次打开是空白项目。旧资料请用“导入旧项目”或“备份与迁移”导入。
4. 制作完成后，用顶部“备份与迁移 → 完整统一备份”另存一份 JSON。

打开 HTML 不需要安装 Node、Python 或启动服务器，也不需要登录卡递。
“开发者源码”仅供查看和修改，不是日常使用入口。

保留的工作流程
- 档案资料、故事时间版本、自定义字段及字段重命名。
- 表格/文本整理、归档预览、保留原文与引文。
- 按模板批量制卡、保留字段映射、卡片与档案跟随关系。
- 精细排版、裁切与出血参数、双击画布输入文字、项目检查与可用的自动修复。
- 图片、PDF、工程文件与完整统一备份导出。

GPT 如何配合
这是本地编辑器，HTML 内不运行 GPT。需要识别自由文本时：
“整理新资料 → 复制给 GPT → 复制原文与指令”，粘贴到当前 ChatGPT 对话。
把 GPT 返回的 JSON 带回“粘贴 GPT 结果”，检查原文引文并确认归档。
无需另配模型 Key。已有结构化表格可直接选择“按表头 / 字段整理”。

资料保存在什么地方
资料自动保存在当前浏览器的本机数据库中，不会写回 HTML 文件本身。
请固定使用同一浏览器、同一文件位置，避免使用无痕模式。
清理浏览器数据、更换浏览器或移动文件后，可能需要重新导入备份。
自动保存不能代替备份；换电脑时带上“完整统一备份”JSON。
单个项目当前上限 30 MB；保留最近 30 次保存快照供恢复。
此文件不会自动同步线上插件内的项目，也不会随包附带你的云端资料。
