## 目录说明

- `cardstudio/`：卡递最新本地版入口、完整源码、构建命令及原交付说明。
- `novel-archive/Novel-Archive.html`：小说档案独立页面，与插件内随附页面字节一致。
- `novel-archive/plugin/`：小说档案完整插件源码，保留原目录与元信息。
- `docs/后续工作思路.md`：后续修复、互通与界面整理的顺序。
- `VERSION.json`：两个来源版本、发布标识及来源文件校验值。
- `MANIFEST.json`、`MD5SUMS.txt`：全部归档文件的完整性清单。

## 使用与构建

下载归档后，用 Edge 或 Chrome 打开两个 HTML 文件。卡递的使用说明见 `cardstudio/先读我.txt`；需要重新构建卡递时，参见 `cardstudio/LOCAL-README.md`，在 `cardstudio/` 中安装依赖后运行 `pnpm run build:local`。

小说档案本地页面即插件内原始页面，无需模型 Key 或业务服务器。插件形态的技能、导入协议与准备脚本一并保留。

## 数据和验证范围

本次归档包含程序、模板逻辑、插件与构建源码，不包含用户浏览器里的卡牌、档案或图片资料，也不改变其存储位置。

卡递在 2026 年 10 月 20 日使用同一 HTML 的本地 HTTP 预览，通过了 13 项真实 IndexedDB 检查，并验证了旧备份恢复、字段关联、出血修改、GPT 结果回填、批量制卡和实际文件导出。测试环境限制了 `file://`，电脑直接双击路径尚未实测。

小说档案源码由当前发布包读取；本次只校验来源、文件大小和归档一致性，没有把重新归档描述为新增功能测试。此前 ChatGPT 统一工作台窗口打不开的问题仍列为待解决事项。

## 回滚约定

保留这份 1.0 基线，后续改动使用新的提交与版本。回滚程序前先导出当前用户资料，再核对清单；程序回滚与用户资料恢复分别操作。任何需要修改、迁移现有真实数据的步骤，先列清单让用户确认。
