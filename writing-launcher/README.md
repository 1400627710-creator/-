# 小说码字助手 Windows 可执行启动入口

此组件只修复启动方式，继续使用 `writing-assistant` 的现有程序和恢复逻辑。码字本体仍是 0.1.2；入口版本为 0.1.3。

作者已确认双击下载的 `.cmd` 后看到源代码，说明文件被文本程序打开。仅凭该现象无法区分扩展名被加上 `.txt`，还是 `.cmd` 文件关联到了编辑器。`START.exe` 直接启动 Windows 的 `cmd.exe`，不通过 `.cmd` 的文件关联，因此无需更改系统默认程序。

下载启动器 ZIP，完整解压，双击 `START.exe`。出现选择框时，选择已经下载的 `author-writing-0.1.2-windows-x64.zip`（不是这个小启动器 ZIP）。入口会完整解压程序并打开码字窗口；已有恢复目录时直接复用。码字窗口打开后保留黑色窗口，它运行本机服务。

Windows 10/11 x64 使用系统 .NET Framework 4.8。入口包含恢复脚本，程序恢复目录与稿件目录分开，无需模型 Key、额外账号或管理员安装。不会更改文件关联或全局执行策略。控制台显示实际错误，出错后保持到按键关闭。

构建：在原生 Windows PowerShell 5.1 中执行 `build.ps1 -Output <绝对 EXE 路径>`。工作流从已发布的完整 ZIP 解压出工具，运行此 EXE 的实际自检、独立恢复、重复启动、HTTP 服务与失败退出检查。自动测试通过不等于作者电脑实际运行已经成功。

独立窗口自动调用当前 GPT 的集成不属于这个启动修复；该部分仍未打通。
