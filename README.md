浏览下载免登录，伙伴投稿只填昵称。创作者在卡递顶部词条库、素材库直接共享、查看完整原稿与图片、反馈、发布并收录；线上更新不自动修改旧卡组。所有者可暂停、邀请指定类别预审、调整范围、下架恢复、备份、撤销设备。

初始内容是四份真实原卡框及用户规则 v0.4 的“再生”。尚未取到的原电脑词条不冒充恢复：新版会从旧保存与旧项目增量收录。

当前分支只提供公开资料服务、素材、词条、规则与开发记录。新版完整核心、管理授权通过私人包交付。旧公开编辑器、旧核心文件已从当前分支撤下；已有 Git 历史与曾经下载的旧代码不会因此消失。

原创规则保持原样；本次不以示例或测试词条替代用户设计。
