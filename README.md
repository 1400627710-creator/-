[下载 Community 1.3.0 ZIP](releases/CardStudio-Community-1.3.0.zip)，解压后打开 `index.html`。

两版词条互通：在 Studio Beta 6 词条库点击“发布到两版词条仓库”与“打开社区版”；可下载包含正式词条设计的离线社区包。社区投稿由私人版审核。共享数据仓库见 [`shared-glossary/`](shared-glossary/)。标准初始库为空，需发布或导入自己的真实词条。
