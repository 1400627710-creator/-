# 卡递 · 统一卡片工作台 1.0.3

私人档案与卡片系统。一个项目同时保存档案原文、任意字段、故事时间版本、卡牌模板、图片、排版与字段映射。GPT 语义识别使用当前 ChatGPT 对话，不需要额外模型 Key。

## 使用

1. 在 ChatGPT 的私人插件中打开“卡递 · 统一卡片工作台”。
2. 点“整理新资料”：粘贴原文并交给 GPT，或按表头 / 字段直接整理。
3. 核对字段与原文引文，点“确认归档”。关闭预览不会写入正式资料。
4. 在“卡片集”选择“从档案批量制卡”，确认类型、模板和字段映射。
5. 点击卡片进入精细排版。支持双击画布输入文字、任意字段显示名称、可调出血、安全距、检查修复、图片和 PDF 导出。

在网站单独打开时，GPT 按钮会保存原文并提供可复制的对话指令；通过 ChatGPT 插件入口打开且宿主提供消息能力时，按钮直接交给当前对话。普通网页预览会显示插件入口，避免将网页 iframe 误认作插件窗口。独立网站的登录在顶层页面进行。演示空间只操作本机合成数据，不连接真实 GPT，不写私人项目。

打开工具仅返回已发起请求；界面完成握手、项目载入与编辑器初始化后，才发送独立就绪回执。工具返回本身不能证明用户窗口已显示。

## 数据关系

- 档案字段编号固定；显示名称可以任意修改，映射不随名称变化而丢失。
- 每张关联卡绑定到确定的档案、故事版本、条目行与制卡规则。重复执行同一规则不会重复生成。
- 档案内容更新时，跟随字段同步。卡面手动修改产生明确覆盖；排版调整保持为卡面设计。
- “字段与映射”可恢复跟随或明确回写档案。回写会更新其他跟随同一来源的卡片。
- 锁定卡牌不自动更新。来源被删除后保留卡片，并标记待处理。删除关联卡后可按原规则补回，不会增加重复关联。
- 切换项目会清空撤销、重做、临时编辑和素材缓存；同项目返回卡片集再打开，仍可正常撤销。
- 归档预览必须有有效原文来源，非空字段不能使用空引文绕过校验。
- 故事时间版本与编辑保存历史分别管理。

## 旧数据迁移

| 来源 | 操作 | 保留内容 |
|---|---|---|
| 小说档案 | 原工具导出 JSON → 本系统导入 → 预览确认 | 类型、任意字段、全部故事版本、表格、窗口布局、编号 |
| 卡递 Beta10 / schema ≤20 | 导出 .cardstudio / 工程 JSON → 在空卡片项目导入 | 卡片编号、模板、排版、词条、素材、锁定状态；补充来源档案与映射 |
| CSV / TSV / Excel | 导入文件或复制表格 | 表头与单元格文本；Excel 首个工作表，归档前预览 |
| 统一备份 | 导入完整 JSON | 档案、卡牌、模板、素材、原文、映射、覆盖状态 |

首次导入档案到空库时保留原始编号；合并到有内容的库时重映射冲突编号并保存对照表。不按相同名称自动合并。完整备份恢复会替换当前项目内容，操作前可备份，服务器保留恢复历史。旧工具浏览器本机数据不会被后台擅自读取。

## 演进顺序与当前边界

1. **已交付：统一私人核心。** 归档、字段、故事时间、编辑器、映射制卡、兼容导入、完整备份、保存冲突保护与 MCP 工具。
2. **下一阶段：迁移验收与规模优化。** 用作者真实备份逐库核对素材、模板、打印输出；增加多工作表选择、字段别名建议与大素材增量存储。
3. **最后替代旧入口。** 公共发布、外部 AI 提供商接入等能力经过验证后，再迁移到统一插件并停用旧入口。

本版不宣布两个旧工具已经退役。公共素材/词条发布、原本机外部模型配置仍使用旧版；统一版隐藏这些未迁移入口。私人工作台服务需要 ChatGPT 身份；预览测试使用演示空间与独立 SQL 测试夹具，生产登录与真实 GPT 往返以插件连接后的状态为准。

限制：单项目 5000 张卡牌；单次原文 15 万字；文件 25 MB；完整快照上限 30 MB。Excel 导入读取单元格显示值/缓存值，不执行宏或重新计算公式。PNG/PDF 由浏览器本地渲染生成。兼容卡递 JSON 包含完整图片，可由旧版直接导入；压缩 .cardstudio/ZIP 作为可选格式。
