卡递与车卡机 · 本地工作台 1.1

请先完整解压，保留文件夹结构。
Windows：双击“卡递启动器.bat”或“车卡机启动器.bat”。
其他系统：用 Chrome / Edge 打开 cardstudio/CardStudio-Local.html 或 novel-archive/Novel-Archive.html。
日常使用不需要 Node、Python、登录或模型 Key。

旧资料不会随程序自动导入。更新前先从旧版本导出完整 JSON 备份，再在新版本中导入。
资料保存在当前浏览器，不能靠复制 HTML 备份。请固定文件位置与浏览器，定期下载完整备份。

卡递：卡片集 → 新建卡片；模板与字段 → 创建/复制模板和适用字段。
车卡机：新建档案 → 编辑字段和条目 → 保存故事时间版本。
互通：打开对方并连接 → 主动发送 → 在接收端预览确认。受浏览器限制时使用互通 JSON 文件。
词条库：定义、别名与示例可手动互传；图片单独管理，定义变更默认保留原内容。
恢复：卡递顶部“保存记录”；车卡机“备份 → 本机保存记录”。
GPT：卡递“整理新资料 → 复制给 GPT”，把 JSON 结果粘贴回来核对引文后归档。

详细修改文件及验证记录见 docs/更新与自检报告.md。
本版保留 GPT 初始版 1.0，不使用小喵代码作为基线。
Windows BAT 和 file:// 双击未在当前测试环境实机验证；相同 HTML 已用本机 HTTP 运行检查。
旧托管地址和已安装插件未更新，不能把本地版可用等同于旧远程入口已修好。
