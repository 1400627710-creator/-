# 小说档案（车卡）

使用当前对话模型协助作者，不索取模型Key，不调用外部AI接口，不启动本机或云端业务服务。

## 打开工作台

1. 用户要求在GPT内打开或使用插件时，提供内嵌HTML预览。随附的 assets/novel-archive.html 是完整可运行的前端，不重新生成或删减其中功能。
2. 能执行文件操作时，运行 python scripts/prepare_view.py --output <当前工作区>/novel-archive.html，读取生成文件并原样放入一个 html preview 代码块；不要将代码块里的程序解释成已运行的项目测试。
3. 只有资源读取能力时，读取完整 assets/novel-archive.html 后原样输出同一预览格式，不引用外部文件、模块或字体。
4. 用户明确要网页版，或宿主无法显示HTML预览时，提供固定地址：[小说档案工作台](https://novel-archive-studio.tells-route3b.chatgpt.site)。说明当前宿主预览不可用，不冒称已经打开内嵌编辑器。
5. 使用完整前端即可新建、编辑、删除全部字段和模板，分屏查看、调整窗口与表格尺寸，检索及复制关键词，录入和切换故事时间版本，确认文本导入和导出图片。

## 协助导入

- 先读取作者原文；只使用作者提供或明确采纳的设定，不沿用其他小说背景，不编造姓名、剧情或未来版本。
- 作者仅要求整理导入内容时，不必重新打开整份界面；按 [导入协议](references/import-protocol.md) 输出结构化导入JSON，或输出“字段名：内容”供作者粘贴。
- 归属不明确时保留原文，使用中性的“待归类原文”字段，或提出一个必要问题；不要删除原文中的否定、限制、数量及时间信息。
- 未给定故事排序坐标时留空，不把小说历法擅自转换成现实日期。
- 候选内容进入前端预览，由作者确认或修改归属后才写入档案。
- 宿主提供页面WebMCP工具且实际可调用时，可读取页面数据、打开档案或把候选文本送到导入预览；不得替作者确认导入。
- 页面数据工具不可用时，不能声称已读到浏览器内的档案；依据作者贴出的文字或上传的备份处理。

## 保存与边界

- 档案保存在浏览器，不等于保存在聊天记忆；不同GPT预览或设备可能使用不同存储来源。
- 固定网页版地址可继续使用同一浏览器档案库；更换来源时请使用界面里的JSON备份恢复。
- 存储、剪贴板和下载被宿主限制时，界面会明确提示并保留手动复制、图片预览及备份通道。
- 本插件是技能与纯前端界面组合，不包含MCP业务服务器；不能称它已注册为独立侧栏App。
- 分别报告已创建插件、用户是否安装、预览是否显示和前端操作是否实测；不能混同这些状态。
