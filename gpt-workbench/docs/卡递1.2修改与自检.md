# 卡递 1.2 修改与自检报告

日期：2026-10-23。基于用户与 GPT 的本地工作台 1.1 修改，冻结的初始版 1.0 保留。此版更新卡递，车卡机入口和原有互通机制保留。

## 五项目标的结果

| 目标 | 实现 |
| --- | --- |
| 透明卡框尺寸 | 读取原图尺寸和透明边界，默认完整显示并锁定比例；支持适配画布、裁切区域或当前区域、手动几何、居中和复位 |
| 素材图层 | 卡框、底纹、图标接入统一图层列表，支持前后顺序、置顶置底、隐藏、锁定、透明度、移动缩放和旋转；普通素材保持原图比例 |
| 一张基础单位模板 | 新项目只展示基础单位卡，七项为名称、种族、系别、效果、费用、攻击、血量；保留旧卡和自定义模板 |
| 法术与建筑 | 同一基础模板提供单位／法术切换；法术隐藏种族、攻击、血量；切回保留原值与布局；建筑不作为新的默认分类 |
| 排版参数出口 | ZIP 包含参数 JSON、中文清单和预览 PNG；支持复制参数；记录实际坐标、图层、字体、素材和出血设置 |
