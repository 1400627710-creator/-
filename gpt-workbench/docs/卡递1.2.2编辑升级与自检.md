# 卡递 1.2.2 · 编辑升级与自检

日期：2026-10-24。基于 GPT 本地版 1.2.1，升级素材透明度、复制、文字增粗和拖动缩放。保留“唯一默认”与车卡机互通，不包含用户浏览器中的真实卡面或私人图片。

## 怎么使用

1. **底图变淡，文字保持不变：**进入“布局”，选中费用、效果等模块，调整“素材 / 底图透明度”。“文字透明度”单独调整。若旧版文字已经发灰，可将文字透明度恢复为 100%，再单独调整底图。
2. **复制素材：**在图层导航选中卡框、底纹、图标或自由图片，点“复制元素”，也可使用 Ctrl/Cmd+D。副本可以独立编辑。锁定素材也能复制，原层继续锁定，副本可编辑；整张卡牌锁定时仍不允许新增副本。图片的附属文字一起复制，跟随关系指向新图片。
3. **加粗而不重新排版：**在“文字”页选择对应文字模块，调整“笔画加粗 · 保持排版”。它不改变字号、字体字重、字宽、文本框或已有换行。“原生粗体”保留原来的功能，可能改变字宽。
4. **缩放素材：**进入布局模式，选中一张图片，拖动四角。勾选“锁定宽高比”可等比调整；保持对角锚点，支持旋转后的素材。数值输入仍可使用。一段连续拖动只需一次撤销。

“素材 / 底图透明度”不会作用于自由文字层；文字层使用“文字透明度”。已经印在位图里的文字属于图片像素，需要先拆成独立文字层才能分别调整。

## 数据与兼容

- 只有实际调整模块时才保存独立透明度，旧卡未操作时沿用原来的显示方式。旧版已经设置的文字透明度不自动重置。
- 笔画粗度保存在相应文字样式中；默认格式、完整项目备份和排版参数均保留相关设置。
- 复制使用新图层编号并复用图片资产，不重复保存同一图片；单独复制附属文字时，副本解除对原图的跟随。
- 图片缩放手柄位于独立操作层，不改变素材的真实前后顺序，且不会进入导出卡面。卡面本身继续按原边界裁切。

## 实际验证

- **63 项 Node 检查通过：**卡递 39 项、共享互通 24 项。
- **23 项真实 IndexedDB 检查通过：**卡递 18 项、车卡机 5 项。使用隔离合成资料库。
- **透明度：**底图分别为 0%、50%、100% 时，原文字透明度保持 0.6，字体与文本尺寸完全一致。
- **复制：**锁定图片生成可编辑副本，附属文字使用独立编号并跟随副本；编辑和缩放副本不改变原层。
- **笔画：**效果文字从 0% 到 100% 强度后，字体参数和全部实际文本矩形一致，原有两行保持不变。
- **缩放：**右上角等比拖动通过；一次撤销恢复原尺寸。旋转 27° 后拖左上角，对角手柄的屏幕偏移小于 0.01 像素。测试中发现的手柄被文字拦截问题已修复并复测。
- **保存与重开：**独立透明度、笔画粗度、图层副本、尺寸及角度保留。
- **导出准备与诊断：**实际导出节点保留独立透明度和笔画样式；生成的排版报告包含 815×1110 预览尺寸、14 个图层和 1.2px 文字笔画。

**验证限制：**本轮测试浏览器的 PNG 下载事件等待超时，未验证实际下载文件落盘；不能将导出节点或预览生成等同于用户电脑下载成功。Windows 启动器、`file://` 双击路径和用户真实“真单位卡”未实机验证。没有修改用户电脑上的程序或浏览器资料。

## 更新方法

先在旧版“备份与迁移 → 完整统一备份”保存资料，然后关闭旧窗口，用本包的 `cardstudio/CardStudio-Local.html` 替换原位置的同名文件，继续使用原浏览器打开。换位置或浏览器时，可导入完整统一备份恢复项目。不要以程序 ZIP 代替私人资料备份。
