# 卡递 1.4 · 档案右栏助手

日期：2026-10-25。基于 GPT 本地版 1.3；复用档案、映射、卡面、模板与保存核心，在“档案资料”右侧增加卡递助手，并更新现有私人 Sites 插件。

## 怎么使用

用户已确认安装“卡递 · 统一卡片工作台”。在 GPT 内打开卡递，进入“档案资料”，右栏连接状态应显示“已连接当前 GPT”。独立本地 HTML 和普通网站显示离线状态，提供格式解析；自然语言理解和修改需要在 GPT 窗口中提交，无需额外模型 Key。

1. 粘贴文本，或点右栏“导入文本”选择 `.txt`、`.md`、`.csv`、`.tsv`、`.json`。单批最多 48,000 字；超过上限会明确提示拆分，不静默截掉正文。
2. 选择“归档并批量制卡”或“仅整理档案”，填写可选处理要求，再点提交。当前 GPT 处理本批原文和必要的项目字段信息；原文中的命令只作为资料。
3. 内容完整且无重名冲突的新增资料自动归档；可制卡条目按项目唯一默认格式生成关联卡，保留原文、额外字段及稳定映射。单位使用七项字段，法术没有种族、攻击和血量，建筑按单位。
4. 缺费用或单位身材时先保存档案，右栏显示待补项。点击条目打开档案填写，再点“生成已补全的卡片”；继续使用原档案编号，不再建一份重复档案。自行填写的数值标为修订。
5. 同名资料先核对；勾选采用时仅新增，保留原档案。值或名称无法在原文定位的条目不能直接采用，需重新整理。
6. “修改已有资料”可选择当前打开档案及关联卡、最近批次，或本项目全部卡片。一次最多 100 张卡／50 份档案，先展示前后差异，点采用后保存。仅修改卡牌七项值与模式，保留排版；卡面覆盖、锁定和档案原始出处继续有效。

本批提交即授权新增；已有资料修改需要在差异预览中采用。处理期间若项目已变化，旧回复保留为过期结果，不自动覆盖。“取消任务”会阻止迟到回复重新激活；已开始提交保存的批次完成后可撤销。

## 保存、撤销与迁移

- 项目保存在当前浏览器 IndexedDB；右栏任务及已收到回复另存于浏览器助手记录，不在服务器保存整套资料库。回复通道只保留短期元数据和加密结果，窗口核对任务、项目和版本后处理，收取后删除通道。
- “撤销本批”仅在没有后续保存时恢复该批次之前的版本。后续有其他修改则拒绝覆盖，可在“保存记录”中核对恢复。
- “撤销补全制卡”只恢复到补全按钮之前，保留已经手填的档案数值和其他先前修改。
- 完整统一备份包含正式档案、已归档原文、卡片、批次、模板、素材和映射。未完成任务、助手聊天记录与连接密钥不随项目备份迁移；迁移前请先完成或取消任务。
- 独立文件、普通网站与 GPT 窗口是不同的浏览器来源，不自动共享本机数据库。首次进入 GPT 窗口，可导入本地完整统一备份。旧云端用户可在已连接右栏选择“从旧云端工作台导入项目”，完整复制为新本机项目，原云端项目保留。旧云端工具与存储继续保留供原入口使用。
