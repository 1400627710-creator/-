# 卡递 1.2.1 · 唯一默认格式

这次增加将一张已有卡的完整视觉格式设为项目唯一默认的功能。用户本机的“真单位卡”尚未由 GPT 查看或应用：浏览器安全规则禁止读取 `file://` 页面。以下验证均为隔离的合成资料，不是用户的真实卡面。

## 应用到你的“真单位卡”

1. 在旧版点“备份与迁移 → 完整统一备份”，确认文件已保存。
2. 关闭旧卡递窗口。将本包 `cardstudio/CardStudio-Local.html` 放到原目录，替换同名程序文件。继续使用原浏览器打开。程序文件本身不保存卡牌资料。
3. 打开你制作的“真单位卡”下那张帮派弟兄，点击编辑器左侧“设为唯一默认”。看到“已设为唯一默认”后，等待顶部显示“已保存到本机”。
4. 在“模板与字段”中可见“唯一默认：真单位卡 · 帮派弟兄”。以后普通新建只使用这一份格式；已有卡片、旧模板和映射保留。可以从旧模板的管理项手动新建其他格式。

若原项目没有自动显示，请先选择正确项目；迁移到其他位置或浏览器时可导入步骤 1 的完整统一备份。不要把空项目导入覆盖原项目。

## 保存什么

保存卡框、插画和图标的素材引用，标准模块和自由图层的位置、尺寸、旋转、顺序、透明度、显示及图层锁定状态，以及字体、数值徽章和图片比例设置。自由文本的文字也随格式保留；新卡的自由图层拥有独立编号。

新卡名称、种族、系别、效果、费用、攻击、血量可以独立填写，不会被帮派弟兄的示例数值覆盖；不继承原卡的发布锁定、家族、扩展包归属或档案链接。单位／法术切换仍使用原规则。

默认格式是点击时的快照。后来修改原卡不会悄悄改变新卡起点；需要采用新排版时，在那张卡上点“更新唯一默认”。重新选择另一张卡设为默认会替换此项目唯一的默认记录，不会改写旧卡。

完整统一备份和完整卡递工程会保留默认设置与所需素材。单独的模板 JSON 仍只导出模板结构，不包含这份项目默认快照和图片。默认格式引用的素材不会被“清理未使用素材”删除。
