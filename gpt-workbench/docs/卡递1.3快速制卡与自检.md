# 卡递 1.3 · 快速制卡、批量修改与文字绑定

日期：2026-10-24。沿用 GPT 本地版 1.2.2 的代码与既有编辑功能，把资料输入、字段核对、归档和制卡接成一条流程。车卡机程序和中文启动器保持原版本。本包不包含用户浏览器中的真实卡牌或私人素材。

## 使用方法

1. 在“卡片集”点 **快速制卡**。每行输入一张，例如：

   ```text
   帮派弟兄，人类，底层，登场：检索一张帮派弟兄。3费1/2身材。
   法术：火花，底层，造成2点伤害。2费
   ```

   也支持有表头的 CSV、TSV 和结构化 JSON。自然描述需要按“名称、种族、系别、效果、费用与身材”的顺序；复杂叙述可点“复制给 GPT”，将当前对话整理的 JSON 粘贴回来。本机页面不调用模型，也不需要额外 Key。
2. 点 **识别并预览**，核对七项字段。缺少费用、单位攻击或血量时会提示，不自动猜数字；可修改、取消采用或返回改原文。法术的种族、攻击、血量保持禁用。确认后同时生成档案、卡牌和字段映射，沿用此项目已保存的唯一默认格式。新建同名卡保留旧卡；同一确认请求重复执行不重复生成。
3. 在“卡片集”先搜索，再点 **批量编辑**。逐格修改后统一保存；未采用的行和锁定字段不写入。卡框、图层、字体和坐标保留；关联档案原文保持原样，手动修改标记为卡面覆盖，继续支持恢复跟随和回写档案。每次显示筛选结果的前 500 张，可进一步搜索缩小范围。
4. 精细排版中选中自由文字，在布局属性的 **内容来源** 选择“跟随费用”等字段。修改数据时本层排版保持；双击绑定文字可直接修改对应卡牌值。图层名显示绑定字段，遵守卡片、图层及对应标准字段锁定。切换法术时，绑定种族、攻击或血量的文字也会隐藏；解除绑定保留当时显示的文字。
5. 制卡或批量保存后，页面提示提供 **撤销本次操作**。仅在此后没有其他保存时直接恢复；已有后续修改则拒绝覆盖，并提示使用保存记录核对恢复。刷新后仍可使用“保存记录”。

单次快速预览为 1～500 张、原文最多 15 万字。额外列保留到档案；表头重复卡牌字段、行中多出未命名单元格、错误 JSON 或无效数字会明确报错。预览中的手动补充与修改记录为修订，不冒充原文引文。

## 更新方法

先在旧版“备份与迁移 → 完整统一备份”导出资料，关闭旧窗口，再以本包 `cardstudio/CardStudio-Local.html` 替换原位置的同名文件，继续使用原浏览器打开。若需迁移，导入完整统一备份。程序包不包含浏览器中的私人资料，不能代替资料备份。
