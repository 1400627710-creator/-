# 本地工作台 1.1 更新与自检报告

日期：2026-10-22。基线：用户与 GPT 的初始版 1.0。真实用户数据未读取或迁移，测试均使用合成资料。

## 功能调整

| 项目 | 具体变化 |
| --- | --- |
| 命名与启动 | 卡递、车卡机及两个中文启动器；卡递默认进入卡片集 |
| 布局与密度 | 收窄外层侧栏、紧凑顶部和标题区、增加有效导航；映射两列显示，窄窗口回落一列 |
| 文字可读 | 名称与标签换行，输入框可查看完整值；修正隐藏编辑器零尺寸测量造成的卡名偏移 |
| 任意改名 | 保留点击字段标签即时保存；空名称不被规范化为旧名称，稳定编号和映射保留 |
| 自由文字 | 双击卡面空白直接添加文本，在内容模式也可直接进入；中文换行、完成、取消与保存均保留 |
| 模板与字段 | 新建、复制、改名、导入导出、停用和恢复；字段适用于全部或指定模板；停用不更改已有卡面 |
| 手动互通 | 主动配对、当前/全部发送、文件备用通道、差异预览与确认；重复和改名按稳定编号识别 |
| 数据保护 | 旧预览拒绝写入，双边修改默认保留本机；保留额外字段、行、故事版本和卡面覆盖 |
| 回传来源 | 关联卡回写原字段，独立卡形成稳定档案；原文引文保留，手动修订单独标明 |
| 共用词条 | 定义、颜色、别名、示例、设计说明可搜索编辑与手动互传；定义变更默认不覆盖，图片单独管理 |
| 保存恢复 | 恢复缓存按顺序提交；车卡机主数据和历史原子写入，保留 30 次历史并可预览恢复 |

## 实际检查

- **46 项 Node 检查通过**：原有 22 项，加互通、模板、传送保护 24 项。
- **卡递 16 项真实 IndexedDB 检查通过**：含 5 MB 以上素材重读、并发写入、30 次历史、互通确认和恢复缓存顺序。
- **车卡机 5 项真实 IndexedDB 检查通过**：重开、旧版本拒绝、主数据与历史原子写入、恢复后新版本及 30 次历史。
- 浏览器走通：新建角色、输入内容、发送到卡递、预览确认、映射批量制卡、改卡回传、原字段更新及重复回传显示相同。
- 浏览器走通：新建模板和必填数字字段；从模板直接制卡；换到法术模板隐藏专用字段；切回后值仍为 7。
- 浏览器走通：双击画布输入中文和换行并保存、任意标签改名、关闭卡递窗口再配对重开，内容仍保留。卡名文字中心实测偏差约 0 px。
- 出血 3 改为 4 mm 后，成品尺寸从 63×88 改为 61×86 mm；恢复默认可用。
- 一键处理 22 项可修复问题，复检剩余 6 项为两张合成卡各自缺插画、缺卡背、待确认生产状态。撤销入口可见，没有把资料缺失冒充已解决。
- 共用词条新增、双向发送、定义变更默认不勾选、显式接受、历史预览及恢复已实测。
- 互通 JSON 已实际导出并通过文件选择器接收；冲突默认保留本机。卡牌输入时收到来件仅提示，焦点未被抢走。
- 实际下载完整备份，检查保留两张卡、一份档案、一份映射、模板字段、词条、任意标签、自由文本及换行，再通过文件选择器恢复到空项目成功。

## 验证边界

本轮使用隔离 Chrome 本机 HTTP 预览。Windows BAT、电脑双击 `file://` 和手机实机未验证；测试环境不允许访问 `file://`。新窗口受限时可用互通文件。旧托管站点及已安装 ChatGPT 插件没有更新，其旧入口问题不因此被宣称修复。

GPT 仍通过当前对话整理、页面预览确认；HTML 不内置模型，也不自动读取聊天记录。模板复用标准模块版式、条件和字段；自由图层仍属于各自卡片。
