# 卡递 1.4.1 · 完整模板保存与迁移

日期：2026-10-26。

## 直接使用

1. 打开你已经排好的布局。在精细排版左侧点击 **导出完整模板**。
2. 填写模板名称，保持 **当前编辑的完整布局**，点击 **生成模板文件**。文件下载为 `卡递模板-名称.kadi-template.json`。刚修改的位置会先完成保存再导出。
3. 下次全新打开卡递，在卡片集、模板与字段或精细排版左侧点击 **导入模板**，选择该文件并确认。
4. 空项目默认勾选“设为以后新建卡片的唯一默认”“应用此模板的出血、字体排版规则和字段标签”“导入后新建一张空白卡”。确认后即可看到布局，以后普通新建和批量制卡继续沿用。

“模板与字段”中的 **导出完整模板** 默认使用已保存的模板格式；如果当前有同模板的卡片在编辑，也可切换为当前编辑布局。这样能分别保留已定稿格式和正在调整的格式。

## 文件保存什么

| 内容 | 迁移行为 |
| --- | --- |
| 模块与自由图层 | 保存坐标、宽高、旋转、层级、显隐、锁定和父子关系。新卡自由层重新分配编号，附属文字仍跟随原素材。 |
| 字体和模块外观 | 保存字号、字体风格、笔画粗细、颜色、对齐、徽章、素材与文字分别的透明度。 |
| 卡框、底纹、插画、图标、卡背 | 把本套模板引用的图片原图嵌入文件，保存尺寸、透明信息、适配、裁剪焦点及缩放参数。未使用的素材不带走。 |
| 字段与条件 | 保存通用／专用字段、条件显示和变量；导入时重新绑定字段与素材编号。 |
| 出血及字段标签 | 随文件保存。已有卡片的项目中，“应用项目设置”默认不勾选；勾选后会作用于整个项目。 |
| 卡片业务内容 | 标准名称、种族、效果、费用、攻击、血量等不作为模板数据复制。自由文字原样保留，绑定文字跟随新卡的数据。 |

模板文件可以单独存到电脑，移动后无需原工程或原素材路径。单文件上限 24 MB；超过上限会提示压缩原图。模板保存字体风格与排版参数，系统字体文件仍由设备提供。此功能不会自动清理浏览器记录；导入模板也不要求先清空资料。

每次导入都添加独立模板，保留同名旧模板与旧卡。导入可以不设为默认，仍能从“模板与字段”指定该模板新建；复制模板也保留已保存的完整格式。旧版 `cardstudio-template` 第 1 版继续兼容；第 1 版文件原先缺少的图片和自由层无法凭空恢复。

## 问题原因与修复

原模板导出只带模板定义、标准主布局、字段和条件。卡片上的自由图层、图片、字体覆盖，以及“唯一默认”保存的完整格式没有进入文件；本卡精调也可能尚未写入主布局。新版把可复用视觉格式独立保存，导出前刷新未完成的保存，提供“已保存模板／当前编辑布局”选择。导入后的模板拥有自己的完整格式，不依赖原卡存在，也不依赖它是否当前唯一默认。

缺少图片、损坏的结构、无效几何和不支持的字段会整体拒绝，失败不留下半套模板；模板引用的素材在尚未创建卡片时也受到引用保护。
