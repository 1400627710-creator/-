# 卡递 1.2 使用说明

先完整解压到固定文件夹，再双击“卡递启动器.bat”。更新前，请在旧程序的“备份与迁移”中导出完整备份。卡牌保存在浏览器中，HTML 是程序文件；更换路径、浏览器或设备时，可在新建的空项目中导入备份。

## 创建单位或法术

1. 点击“新建卡片”，选择唯一的初始模板“基础单位卡”。
2. 输入名称、种族、系别、效果、费用、攻击、血量。
3. 示例：帮派弟兄；人类；底层；登场：检索一张帮派弟兄。；费用 3；攻击 1；血量 2。
4. 在右侧“卡牌模式”选择法术，种族、攻击、血量会同时从编辑区和卡面隐藏。切回单位会恢复原值与排版。
5. 点击字段名称旁的笔形按钮可以任意改名，修改即时保存。双击画布空白位置可以直接输入文字，Ctrl + Enter 完成。

建筑不单独设置初始模板。新项目只显示基础单位卡；导入旧工程时，已有卡片及其旧模板继续保留。旧卡可由你主动切换到基础模板，再选择单位或法术模式。

## 导入和调整透明卡框

1. 进入卡片编辑器，点击“布局”。
2. 点击右侧“＋ 导入透明卡框”，选择之前的 PNG。已有透明度会保留；普通非透明图片仍可通过原有转换流程处理。
3. 在左侧“图层导航”点击“透明卡框”。右侧会出现“图片适配”和素材原始尺寸。
4. 选择“完整显示 · 保持比例”，再选择“整张画布（含出血）”或“裁切后的成品区域”，点击“应用适配”。
5. 在“位置与尺寸”中输入 X、Y、宽、高、角度或层级。图片默认锁定比例，改变宽度会同步高度；拖动右下角也可缩放。
6. “居中”以整张画布为中心；“复位”恢复到导入时的位置和尺寸。上述设置会随卡片保存。

之前的透明卡框是 946 × 1340。它与 69 × 94 mm 画布的比例不同，完整适配后左右会有少量空隙，这是保留原图比例的结果。需要铺满指定区域时，可选择“填满区域 · 居中裁切”；“拉伸铺满 · 自由比例”会改变图像比例，由你自行选择。

“裁切 / 出血”按钮可打开出血与安全区设置。红线表示裁切边界，绿线表示安全区。默认画布 69 × 94 mm、四边出血各 3 mm，对应成品 63 × 88 mm。

## 调整图层

卡框、底纹、图标、插画、字段和自由文字统一显示在图层导航中。

- 点击图层名称选中，再使用右侧“上移一层、下移一层、置顶、置底”。
- 点击图层左侧圆点显示或隐藏，点击右侧锁形图标锁定或解锁。
- 使用透明度滑块改变选中图层的不透明度。
- 普通小素材用“＋ 导入小素材 / 图标”导入，也会按原图比例放入，支持移动、缩放、旋转和排序。
- 旧卡的卡框保留原来的位置与拉伸方式。需要校准时，选中该卡框后主动应用适配。

常见顺序是：文字与数值在上，透明卡框居中，插画在下。锁定卡需要先解除发布锁定后才能调整。

## 把排版参数发给 GPT

1. 打开需要检查的那张卡。
2. 点击画布下方“导出排版参数”。
3. 参数包生成后，可点击“下载：卡名-排版参数.zip”。浏览器允许时会自动开始下载。
4. 将 ZIP 上传到当前对话即可。包中有“参数.json”“排版说明.txt”“卡面预览.png”。
5. 也可以点击“复制排版参数”，直接粘贴到对话。浏览器不支持自动复制时，会显示可全选复制的文本框。

参数记录当前卡的七项内容、画布与出血尺寸、各图层坐标、尺寸、顺序、角度、透明度、锁定状态、字体，以及图片原始尺寸和适配方式。插画还记录焦点、主体位置和缩放。诊断包不附带原始素材文件；备份全部卡片及原始素材仍使用“备份与迁移”。
