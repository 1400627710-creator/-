# 卡递共享资料服务 1.0.0

线上入口：https://cardstudio-community-hub.tells-route3b.chatgpt.site/share/index.html

这里公开共享词条、素材、投稿审核的服务模块与界面，不包含卡递完整版制卡核心。社区制卡编辑器已取消，当前服务部署使用同一 D1 / R2 数据库。

浏览下载免登录，投稿只填昵称。完整管理权限由卡递本机服务器保管的设备授权控制，不依据 ChatGPT、Google、Apple 账号。管理凭证、安装授权禁止提交 Git。

## 验证

Node.js 24：`npm ci` 后 `npm run check`，独立内存数据库执行 19 项行为检查，测试资料不会上传生产。

`app/kadi-api.mjs` 的 `handleKadi(request, env)` 使用 `env.DB` 和 `env.BUCKET`，返回标准 Response。Cloudflare 初始化时向 image-codec.mjs 的 setWebpModule 传入 @jsquash/webp/codec/dec/webp_dec.wasm 的编译模块。本目录提供已经部署的业务源码与可独立运行的检查，不负责创建新云账号或数据库。

D1 schema 位于 db/schema.ts，drizzle/ 保留原迁移并追加 kadi_* 表；R2 保存真实像素解码后重编码的 PNG 与缩略图。受限解压使用公共 zlib，四份原卡框的像素与透明度校验通过。

## 资料与权限

词条保留完整定义、规则体系、别名、示例、设计说明、署名、来源。同名不同定义可共存，更新携带当前修订，冲突整批回滚，不改变旧卡组。

图片限制 15MB / 420 万像素，禁止 SVG、动画、伪装文件。重新编码去除附加元数据，本机原图独立保留。每人每日 40 项、同来源每日 200 项，待审核 500 项；图片按唯一二进制预留 512MB 总预算，失败、撤回、更换昵称不能绕过。

所有者直接共享、查看完整原稿、给反馈、发布并收录、暂停投稿、调整范围、按类别邀请预审、下架恢复、撤销设备。预审授权不能发布。伙伴只看自己的投稿，导出投稿凭证可恢复进度。

完整备份不包含原始管理凭证；卡递收集本机原图及共享历史。恢复默认增量收录到“我的”，不覆盖项目或云端。历史回滚产生新修订。

真实初始资料是用户四份原卡框和《添加规则 v0.4》的“再生”。尚未明确的手牌上限、费用仍在设计说明中标记待定。演示词条不作为原设计上线。线上为当前共享来源，shared-glossary / shared-assets 为初始快照。开发日志、自检见 ../card-studio/。
