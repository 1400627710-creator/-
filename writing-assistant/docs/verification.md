- R1：本机插件包、真实 STDIO 和当前模型写回已验证；桌面安装与窗口组合保留未验证状态。
- R2、R8：本机编辑、小说隔离、排序命名、撤销、导出和存稿恢复已实现并检查。
- R3：真实任务产生了有准确出处的记忆；纠错停用与确认、来源迁移和 AI 文风隔离已检查。
- R4：分支修改与迟到任务拦截已测试；原生 ChatGPT 历史不会被本工具改写。
- R5、R6：候选只能采纳选段、可撤销；样本缺失拦截与 ASK 协议通过；语义与文风不能只靠结构校验判定，作者评审仍待完成。
- R7：前台调度、每五分钟最多一次、手动优先已测试；真实宿主自动推理未验证。

## 复现

`npm ci` → `npm run typecheck` → `npm test` → `npm run build` → `node --test tests/setup.test.mjs`。

安装 Playwright 测试依赖与 Chromium 后，运行 `node tests/browser-flow.mjs` 和 `node tests/app-bridge.mjs`。可通过 `WRITER_PLAYWRIGHT` 和 `WRITER_CHROMIUM` 指定已有模块与浏览器路径；截图中文字体可通过 `WRITER_QA_FONT` 指向仅测试用的 Noto Sans SC 包，不属于运行依赖。

`node tests/live-session.mjs <测试输出目录>` 提供官方 SDK 的交互会话，用于当前模型真实分析与写回。`tests/fixtures/host-polish-reply.json` 是合成测试原稿的实际 GPT 首个回复，供 UI 回放。严禁将作者真实请求、回复、备份或运行状态加入发布清单。

## 作者电脑的最后验证步骤

安装并重启桌面客户端 → 新聊天打开码字窗口 → 导入你愿意给 GPT 看的短段 → 选段润色 → 看到候选并采纳 → 撤销 → 在记忆栏纠正并确认。

然后开启小建议，新增一段、停笔至少30秒，检查是否得到一条实际 GPT 建议。若客户端缺少消息/UI 能力，使用已测试的网页文件接力流程继续写作，并保留本项未通过状态。安装说明见 [README](../README.md)。
