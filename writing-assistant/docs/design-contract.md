# 已确认目的与实现约束

作者想保留自己的小说表达，利用当前 GPT 推敲与码字，避免廉价修辞、误读原意和不合理情节。

| 作者要求 | 实现入口 |
| --- | --- |
| 无需额外注册或填写 Key | 当前 GPT 宿主；网页文件接力；不内置第二个模型 API |
| 本机完成码字、GPT 插件与方便的窗口 | 本机 Node.js 存稿服务、官方插件包及 MCP Apps 编辑资源 |
| 左仓库、中正文、右聊天，撤销与批量导出 | React 三栏编辑器与 UTF-8 导出 |
| 学习作者内容、世界社会人物物品及文风 | 当前 GPT 分析，准确原文跨度与有效记忆检索 |
| 自动记忆允许纠错，纠正可须确认后正式使用 | auto/pending/confirmed/rejected/stale 状态；作者窗口专属确认 |
| 编辑撤回问题，让 AI 再思考 | 新有效分支、旧任务与旧候选失效 |
| 润色保留原意，不乱加内容 | 约束协议、选段差异与采纳、修订校验；语义最终由作者评审 |
| 代笔可补动作心理对白，必须理解内容与想法 | 原文、适用作者样本和人物所知；不足先问；候选采纳 |
| 偶尔主动小建议 | 前台新增段落、停笔30秒、五分钟节流、手动优先；真实宿主待验证 |
| 上传 GitHub 公私均可 | 仅上传工具代码、测试合成资料、开发记录与发行包 |

中继器已实际诊断并校验先前的开发指令。采用作者已确认的模块和验收方向；本目录是项目实现，中继器仍负责需求编译，不替代代码测试。技术参数沿用已确认的默认假设。

不以“规则写进提示词”证明 GPT 已充分理解；每次上下文显示加载范围。记忆是带出处的记录，不是微调训练。不能在作者样本缺失时宣称达到作者文风。
