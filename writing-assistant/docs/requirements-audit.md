## 当前阻塞

作者已提供 `[ARCHIVE_INCOMPLETE] Extract the entire ZIP before running this file.` 与退出码 1。该文字只出现在旧 `.cmd` 找不到同目录下 `scripts\windows-launch.ps1` 的分支，发生在 PowerShell、Node 和本机服务启动前。按回车关闭是 `pause` 后退出的行为。尚不能仅凭这段输出确认作者是从 ZIP 预览运行、部分解压、移动了入口，还是遇到解压兼容问题。

已检查发布的 0.1.1 Windows 完整 ZIP：配套脚本存在，但全部 3859 个条目都使用反斜杠。旧测试覆盖的是压缩前的准备目录，没有覆盖最终 ZIP 解压启动；这两点是可确认的交付缺陷，不能直接等同于作者本机故障的唯一原因。

0.1.2 使用标准正斜杠 ZIP 条目，增加可单独运行的恢复启动器：选择已下载的完整 ZIP 后自动完整解压，兼容旧反斜杠包，保留失败信息。发布工作流先制作最终 ZIP，再实际解压并运行 Windows 原生启动、安装和恢复检查。实际账户插件加载、自动 GPT 回写、主动建议与作者电脑运行结果仍需验证。

## 完成标准

必须在作者实际客户端中完成：启动窗口 → 保存并重开 → 提问 → 当前 GPT 实际回写 → 采纳选段 → 撤销 → 编辑原问题重问 → 纠正记忆并确认。主动建议还需在该客户端内实际触发模型回复。以上未通过时，版本状态保持“未完成作者端验收”，不以文件接力或模拟宿主结果代替自动直连验收。
