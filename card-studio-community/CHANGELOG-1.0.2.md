# CardStudio Community 1.0.2

本版本只做稳定性、安全边界和低风险体验收敛，不新增 Studio 级复杂能力。

## 修复

- 打开 `.cscard` 时严格要求 `format: cardstudio-community`，并限制项目大小、卡牌数、单卡模块数和词条数。
- 项目中的底图只接受 PNG / JPEG / WebP Base64；普通 SVG、外部 URL 和异常 Data URL 不会进入卡面。
- 新建项目与打开项目现在会正确隔离“本项目共创词条”，不会把上一个项目的投稿词条串到下一个项目。
- 旧项目中伪装成 `official` 的本地词条不会获得共享词条身份；共享词条仍以只读发布库为准。
- 共创词条禁止 `[`、`]` 和换行，避免破坏 `[[词条]]` 引用语法。
- 共创词条改名后，会同步更新当前项目全部卡牌中的对应 `[[旧词条]]` 引用。
- 修复双击文字后立刻点击项目/导出时，可能仍导出旧文字的问题：离开内联编辑器时先提交数据，再延迟重绘界面。
- 修复调整位置、字号、对齐等普通属性会错误关闭“自动对比色”的问题；只有手动选颜色才退出自动模式，“自动对比色”按钮会重新进入自动模式。
- 底图读取失败、损坏图片和超大像素图片现在会给出可见错误，不再留下未处理 Promise。
- 底图增加 12000px 单边 / 6000 万像素上限，减少异常超大图片造成浏览器内存压力的风险。
- 在线 `shared-glossary.json` 改为后台加载，不再阻塞制卡器启动，并增加 3.5 秒超时与 5MB / 5000 词条边界。
- IndexedDB 恢复增加超时与 blocked 处理；本地存储异常时仍可进入安全空白项目。
- 在词条搜索框、词条编辑输入框中按 Esc 现在也能按层级关闭弹窗。
- 词条渲染与 PNG 导出统一：`[[词条]]` 在两处都保留词条颜色和粗体表现。
- 修复极窄窗口下预览字号和最终 PNG 比例偏差过大的问题。

## 低风险优化

- 手机端不再隐藏“项目”入口，因此移动端仍可打开 / 导出 `.cscard`。
- 手机端属性面板移到画布下方，不再固定遮挡卡面。
- 手机端顶栏压缩为“底图 / 词条 / 项目 / PNG”，保留四条核心工作流。
- 删除右侧无实际编辑价值的固定 69×94mm 输入框。
- 删除画布底部长期占位的版本边界说明，仅保留当前状态信息。

## 验证

除 Node 静态/运行时检查外，本版新增真实 Chromium DOM 交互验证，覆盖：

- 默认启动与隐藏弹窗
- 词条库按需打开
- 特殊字符词条安全显示
- 共创词条创建、插入、改名与引用迁移
- 双击文字后立即导出 `.cscard`
- 新建/打开项目的词条隔离
- 非 Community JSON 拒绝
- 撤销 / 重做
- PNG 底图导入
- 1380×1880 PNG 实际下载与尺寸验证
- 390px 移动端核心入口可见性

自动化环境禁止直接导航 `file://` / localhost，因此自动浏览器使用同一份 HTML/CSS/JS 注入真实 Chromium DOM 完成交互测试；直接双击文件的 Windows 路径仍以实际用户机器为最终运行环境。
