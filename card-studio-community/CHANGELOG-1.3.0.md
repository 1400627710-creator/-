# CardStudio Community 1.3.0

更新日期：2026-10-05（北京时间）

社区版现在可以查看 Studio 发布的完整词条设计，并把共创词条送回私人版审核。仍可直接双击 `index.html` 使用。

- 正式词条完整展示颜色、分类、标签、定义、检索别名、使用示例和设计说明，搜索也包含新增设计字段。
- 新增“同步私人版词条”“提交到私人版审核”和“导入词条文件”。从 Studio 打开的社区版直接接入同源共享仓库。
- 投稿只包含自己的共创词条；正式词条只读，不重复投稿。离线或独立静态网站通过按钮导出投稿 JSON。
- 正式词条随自动保存和 `.cscard` 一起保留；刷新或转交项目不会丢失完整设计。当前项目格式仍为 v3，继续读取 v1/v2。
- 后台读取空的初始库或旧快照时保留已有词条；主动同步或导入可明确选择新的正式快照。
- 公共校验模块统一两版字段、旧格式兼容和容量限制，拒绝非法 ID、重复名称及异常字段。
- 直接打开离线包不请求网络；词条读取超时不阻塞编辑。正式共享词条无法在社区版直接改写。
- 浏览器回归增加私人版词条设计、颜色引用、刷新和项目往返检查。

验证：常规自检通过；本目录真实浏览器回归 4/4 通过；两版联动的词条流程 6/6 通过；原有双版本浏览器流程 11/11 通过。完整记录见 `VERIFICATION-2026-10-05.md`。

标准源码包的初始词条库为空。要查看自己的词条，请在 Studio Beta 6 发布后点击“打开社区版”，或从 Studio 下载含词条的社区版。
