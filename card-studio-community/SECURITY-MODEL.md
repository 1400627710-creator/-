# Community 安全与数据范围

普通制卡、项目保存和 PNG 导出在浏览器内完成。公共资料从内置 HTTPS 公共仓库读取；投稿通过该仓库的验证登录身份提交，仅上传选择的词条设计或图片，不上传整份制卡项目。审核和公开发布仅由管理员执行，管理凭据只留在私人版的本机服务中。公共署名使用投稿时的作者名，不公开账号邮箱或内部身份 ID。

词条采用白名单字段；名称、数组数量和文本大小有界限；界面按文本转义显示，不执行定义中的 HTML。图片限制 PNG/JPG/WebP、15MB、尺寸和像素数量；未审核原文件仅作者和管理员可读。正式图片按哈希提供固定版本，旧作品本地副本继续有效。

新建和采用的资料保存在当前浏览器；地址变更不自动迁移 IndexedDB。资料库提供本地删除，删除本地条目不撤下公共资料。项目和离线文件仅用于用户主动备份与旧格式兼容。

支持登录前暂存所选投稿，登录后按实际保存的 ID 恢复。跨窗口接收校验来源、窗口及随机标识；跨站直接写入被服务端拒绝。错误不会显示为成功或自动覆盖旧资料。
