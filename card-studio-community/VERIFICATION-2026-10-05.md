# CardStudio 两版词条互通使用说明与验证记录

更新日期：2026-10-05（北京时间）

本次交付 **Studio 3.0.0 Beta 6 私人版** 和 **Community 1.3.0 社区版**。社区版能够查看私人版发布的完整词条设计，包括名称、颜色、分类、标签、完整定义、检索别名、使用示例和设计说明。社区投稿经私人版审核后再发布。

## 第一次使用

1. 解压私人版安装包，双击 `安装并启动.bat`。已有 Node.js 22 或更高版本时可直接启动。
2. 打开自己的 `.cardstudio` 项目，进入“词条库”，确认词条内容。
3. 点击 **发布到两版词条仓库**，再点击 **打开社区版**。
4. 社区版打开“词条库”，选择词条即可查看完整设计；私人版后续再发布时，点击社区版“同步私人版词条”。

安装包内已带社区版，无需自行复制源码或配置接口。开发环境无法读取你电脑浏览器里的词条，因此仍需要第 2、3 步；正式交付包未把测试示例当成你的规则。

## 发给群友离线使用

在私人版词条库点击 **下载含词条的社区版**，把下载的 ZIP 发给群友。对方解压后直接打开 `index.html`，无需安装 Node 或任何依赖，即可查看已经发布的设计、制卡和导出 PNG。

单独下载的标准 Community 1.3.0 源码包以空词条库起步。要让它带上自己的词条，使用上述下载按钮，或在私人版“导出共享词条”后，通过社区版“导入词条文件”导入。

## 社区投稿回到私人版

1. 社区版点击“＋ 共创词条”，填写并保存自己的设计。
2. 点击 **提交到私人版审核**。
3. 私人版点击 **接收社区投稿**，查看原设计与待合并内容。
4. 新词条默认选中；设计冲突默认保留原内容。需要采用修改时明确勾选；取消会保留投稿等待后续审核。
5. 点击确认完成该份投稿审核。未勾选的修改按拒绝处理。确认后在私人版再次点击 **发布到两版词条仓库**，社区版再同步。

离线社区版或独立静态网站点击投稿按钮会导出 JSON 文件。把文件交给私人版，通过“导入共享词条”进行相同的预览与合并。

## 保存和升级

两版使用统一词条格式 `cardstudio-glossary-v1`，旧词条缺少新设计字段时仍能读取。检索别名用于搜索，卡面引用仍使用正式名称 `[[词条]]`。

正式词条保存在私人版安装目录 `shared-data/glossary.json`，待审核投稿保存在 `shared-data/contributions.json`；关闭和重启工具不会丢失。以后换新版安装目录时，先停止旧服务，再复制整个 `shared-data` 文件夹。现有制卡项目通过导出和打开 `.cardstudio` 迁移。

社区版把正式词条快照随自动保存及 `.cscard` 保留，群友重开项目仍能查看设计与颜色。自己的共创词条属于当前项目，新建项目会清空这部分内容，避免不同项目串库。

## GitHub 更新范围

公开仓库更新 Community 1.3.0 源码、共享格式、版本日志、验证记录和社区版 ZIP。`shared-glossary/glossary.json` 是仓库中的正式词条快照；开发者可用同步脚本同时更新在线 JSON 和离线快照，再提交 GitHub。Studio 能导入同一文件并预览合并。

私人版核心继续只随私人包交付。应用发布按钮写入本机共同词条仓库，不会自动上传自己的本地数据到 GitHub，也不需要在应用里配置 GitHub 密钥。
