# CardStudio Community 1.0.0

首个独立公开共创版本。

## 三个产品约束

- **简洁**：主链路只有选卡、改卡、查词条、导出。
- **共创**：`.cscard` 可直接分享；词条使用 `cardstudio-glossary-v1` 与 Studio 互通。
- **高效**：双击卡面文字直接编辑、拖动模块、图片一键/拖拽导入底图、PNG 一键导出。

## 安全边界

Community 是全新静态网页实现，不包含 Studio 的 Master Template、Schema、Preflight、AI Provider、Asset Store、Set/Family、版本发布、专业印刷/TTS 等代码。
