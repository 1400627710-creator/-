# CardStudio Community 1.1.0

## 旧版完整自由模式回归

Community 继续默认保持轻量制卡流程；按 `L` 或点击“自由模式”后进入高级编辑层。

- 标准字段与自定义元素都作为独立图层处理。
- 新增自由文字、卡牌编号、栅格图片 / 图标。
- 支持拖动、框选、Ctrl/Cmd 多选、Shift 追加选择。
- 支持整组选区移动与缩放、锁定宽高比、旋转。
- 支持智能吸附与横纵参考线。
- 支持六向对齐、水平 / 垂直等距分布。
- 支持透明度、显示 / 隐藏、锁定 / 解锁、层级上移 / 下移 / 置顶 / 置底。
- 恢复图层列表与完整几何参数 X / Y / 宽 / 高 / 角度 / Z。
- 图片可附加中央 / 上 / 下 / 左 / 右文字；跟随移动并可解除关联。
- 恢复自由文字内容、字号、字重、颜色、对齐与四类字体样式。
- 标准文字槽位可把文字样式安全同步到全部卡牌。
- 双击文字直接编辑；自由模式双击空白新增文本。
- 标准模块删除时改为隐藏，自由模块才真正删除。
- “布局应用到全部卡牌”只同步稳定标准槽位，自由元素不复制到其他卡牌。

## 快捷键

- `L`：切换自由模式
- 方向键：0.2% 微调
- `Shift + 方向键`：1%
- `Alt + 方向键`：0.05%
- `Ctrl/Cmd + A`：全选可见、未锁定图层
- `Ctrl/Cmd + D`：复制选择
- `+ / -`：缩放选区
- `Q / E`：旋转
- `[ / ]`：调整层级
- `Delete`：隐藏标准模块 / 删除自由模块
- `Esc`：清空选择

## 项目格式

`.cscard` 升级到 Community Project v3。底图与自由图片统一进入去重资源表，避免同一图片重复嵌入。仍可读取 v1 / v2 项目。

## 安全边界

公开版仍只接受 PNG / JPG / WebP 栅格图片。旧版 SVG 小素材没有恢复，这是公开网页安全边界，而不是编辑能力缺失。Studio 私有生产系统、AI Provider、Master Template 等仍未进入 Community 源码。
