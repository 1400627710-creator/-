# Community 1.4.0

2026-10-05，北京时间。与 Studio 3.0.0-beta7 共用线上公共资料仓库。

- 词条库 / 素材库入口保持顶部可见，统一为“公共 / 我的 / 投稿状态”。
- 公共词条显示完整定义、颜色、分类、别名、示例和设计说明；可加入自己的项目或直接用于选中的文字模块。
- 公共素材显示图片、分类与说明，直接加入我的素材或插入卡面；保存采用的图片原文件。
- 在线社区版登录后直接投稿词条或图片，私人版可收到并审核。未审核投稿不会出现在公开库中。
- 独立下载版和 file:// 离线版可打开在线投稿窗口带入选中资料。登录跳转后自动恢复，确认提交即可进入待审核区。
- 断网保留已加载的公共缓存；清楚区分“仓库已连接且没有资料”和“连接失败”。
- 项目保留使用过的词条设计与图片快照。刷新公共仓库不自动改写已有作品。
- 旧 .cscard、glossary.json、Studio 词条导出及 .csassets 格式继续兼容。文件导出作为备份。

在线入口：https://cardstudio-community-hub.tells-route3b.chatgpt.site/community/

首次正式发布前，公共库显示为空；私人电脑中的项目不会自动公开。管理员在私人版主动发布后，所有社区客户端从同一线上仓库读取。
