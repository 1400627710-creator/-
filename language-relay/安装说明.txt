语言转换指令中继器 私人版 1.1.2 — 安装与连接说明

一、你的电脑已有 Python 3.14.8，可以继续使用

1. 关闭旧版启动窗口。
2. 右键新版 ZIP，选择“全部解压”，进入 language-relay 文件夹。
3. 如要保留旧历史，将新版代码替换到原项目文件夹，保留原来的 .data 和 .env。
   同一电脑升级时保留 .data 中的密钥与授权文件，不要用空文件覆盖。
4. 双击 start.bat。首次升级会自动检查并安装新依赖，保持联网。
5. 网页就绪后自动打开；没有自动打开时，将启动窗口的完整网址粘贴到浏览器。
   使用期间保持窗口打开。关闭窗口停止服务，历史不会因此删除。

命令行启动：在项目文件夹的资源管理器地址栏输入 cmd，按回车，然后执行：
py -V:3.14 bootstrap.py
也可以执行 py bootstrap.py。无需另外安装 Python 3.11。

二、不想输入 Key：使用官方 ChatGPT 登录

1. 点击网页“连接与设置”。
2. 将“模型连接方式”改为“使用 ChatGPT 登录（免 API Key）”。
3. 点击“使用 ChatGPT 继续”。
4. 在 OpenAI 官方页面登录你的账号，按页面提示授权本应用使用 ChatGPT 计划。
5. 返回中继器，确认账户和可用模型。若模型没出现，点击“刷新可用模型”。
6. 如果页面没有同步，点击“检查登录状态”，查看具体阶段或失败原因。
7. 点击“保存并检测连接”。显示“连接检测通过”后即可发送想法。

你不需要把账号密码或 API Key 发给任何人。
免 API Key 方式仍然需要官方登录与授权；是否可用取决于账户、地区、工作区、
模型权限与额度。此对话的模型是否能选，由账户返回的列表决定。
官方拒绝时，应用显示失败阶段并保留安全错误码；通用 403 不能确定具体资格原因。

三、官方页面已登录，应用仍未同步时

打开“连接与设置”，选择 ChatGPT 连接，点击“检查登录状态”。

显示“等待官方授权返回”：在刚打开的官方页面继续完成本应用授权，并返回中继器。
只在 ChatGPT 网站登录账号，不等于允许本应用调用模型。
显示“账号已登录，模型尚未授权”：账号身份已经确认；重新点击“使用 ChatGPT 继续”，
按官方页面允许使用计划。账户不符合条件时，应用会保留并显示官方接口的失败原因。
显示“已收到回调”：保持启动窗口打开，等待本机完成验证。
显示网络错误：网页能登录与本机程序能连接接口分别检查，换 Key 无法修复网络。
显示服务重启中断或等待过期：回到应用重新开始登录，完成新的授权。
显示模型列表尚未加载：点击“刷新可用模型”，已验证的登录不会因此删除。

刷新页面会继续检查等待中的登录，不用重复点击登录。
需要重新打开官方页时，按钮会沿用当前请求；要重新开始，先点“取消本次登录”。
失败原因在刷新和重启后仍能显示。

本次新增“一键自检并导出”：登录出错后直接点此按钮，发送下载的 JSON。
报告记录阶段、HTTP 状态、安全错误码、请求 ID 和环境，不含密钥、令牌、
邮箱或会话。可取消网络检查只查本机；网络检查不调用模型，不消耗模型额度。
页面打不开时，把 diagnose.py / diagnose.bat 放到原项目，与 start.bat 同级，
双击 diagnose.bat，从旁边 diagnostics 文件夹发送最新 JSON。
也可运行：py -V:3.14 diagnose.py --offline
旧版未记录的细节无法还原。要定位具体的授权拒绝步骤，升级后再登录一次。
完整说明见 诊断使用说明.txt。

四、继续用 Key：一步导入并检测

1. 打开“连接与设置”，选择“OpenAI API（使用密钥）”。
2. 粘贴完整的 OpenAI API Key，点击“导入并检测”；
   或点击“选择密钥文件并检测”，选择 .txt、.env 或 JSON 文件，自动导入和检查。
3. 根据显示的中文结果处理。检测失败时已经导入的密钥会保留。
4. 修改模型或温度后，点击“保存并检测连接”重新确认。

已保存不是已验证。检测发送一条简短测试，会使用对应 API 或计划额度。
密钥文件最多 16 KiB；导入不会上传历史，也不会在页面回显密钥。

提示 API Key 无效：从 API 平台重新复制完整密钥并导入。
提示 API 额度不足或未启用计费：检查 API 平台余额、项目与计费。
API 计费与 ChatGPT 订阅分别管理。
提示模型或权限不支持：选择账户可用、支持结构化输出的模型。
提示无法连接或超时：检查访问 OpenAI 官方接口的网络，换密钥无法修复网络。
提示 ChatGPT 授权失效：重新使用 ChatGPT 登录。
提示 ChatGPT 额度达到上限：点击输入区旁“管理额度”，在 ChatGPT 设置中处理。

五、中继器的使用目的和输出规则

输入“我想做卡牌游戏”并发送。信息不足时只显示第 3 节，最多问 5 个问题。
你可以补充回答，也可以说“使用默认假设，我需要结果”或点击同名按钮。
生成完整结果时固定为：
1. 我理解的想法
2. 动机分析
3. 需要确认的问题
4. 需求规格
5. 技术方案
6. 给编程 AI 的指令
7. 自检

未明确提供的内容标记“假设”。必须做与可选做分开；模糊要求会量化。
第 6 节包含十个必需部分，可直接复制给编程 AI。
点击“复制 Markdown”“复制第 6 节”或“导出 .md”使用结果。

六、安装或网页打不开

网页本身不需要 Key。整页打不开时先查看启动窗口，而不是重复导入 Key。
提示 No runtime installed that matches 3.11：执行 py -V:3.14 bootstrap.py。
提示下载失败：检查网络后重新双击 start.bat，会重新检查和重试安装。
提示无法写入：把完整项目解压到桌面或文档中的普通文件夹。
提示已有窗口：使用原启动窗口显示的网址。
端口占用时：使用窗口显示的备用网址，不要固定输入 8000。
持续失败时运行 diagnose.bat，提供安全诊断 JSON；不要发送密钥、账号密码、授权文件或原始日志。

更换电脑：可迁移代码、历史和 API 配置；不要复制 .venv 或 .data/chatgpt-auth.json。
在新电脑重新使用 ChatGPT 登录，由程序建立新的本机注册身份。
macOS / Linux 在项目文件夹执行 sh start.sh；需要完整 Python 3.11 或更新版本。
