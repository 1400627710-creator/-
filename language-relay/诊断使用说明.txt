语言转换指令中继器 · 一键自检 1.1.2

你这次的两个提示：
第一条是旧版将所有 HTTP 403 合并显示为账户、地区或工作区限制。
因此不能仅凭该提示确定实际原因。第二条表示本机没有可用的计划授权，
通常是前一次授权失败的后续结果。刷新模型列表不会重新完成授权。
官方网站登录账号、允许使用计划、本机验证并保存授权，是不同步骤。

方法一：新版页面可正常打开
1. 关闭旧启动窗口，将 1.1.2 完整解压到原项目并覆盖代码。
   保留 .data 和你自己的 .env；不要删除会话或授权文件。
2. 双击 start.bat。打开连接与设置，使用 ChatGPT 继续，完成一次登录。
3. 出错后直接点击“一键自检并导出”。浏览器会下载 relay-diagnostics-*.json。
4. 把这一份 JSON 文件反馈给开发者即可。

方法二：旧版或页面打不开
1. 将 diagnose.py、diagnose.bat 放到中继器项目目录，与 start.bat 同级。
2. 保持中继器启动窗口打开。双击 diagnose.bat。
3. 打开旁边的 diagnostics 文件夹，发送最新的 relay-diagnostics-*.json。
   诊断工具仅需 Python 3.11+；不需要先安装 FastAPI 等依赖。
   你现有的 Python 3.14.8 可用，也可在命令行运行：
   py -V:3.14 diagnose.py

如果有多个中继器窗口，用启动窗口显示的端口运行：
py -V:3.14 diagnose.py --port 8001
只做本机检查、不连接官方服务：
py -V:3.14 diagnose.py --offline
项目在其他目录时：
py -V:3.14 diagnose.py --project "C:\路径\language-relay"

程序检查哪些内容
- Python 版本、位数、Windows 构建号与运行进程的依赖版本。
- 本机服务、数据目录写入、授权记录是否可读取。
- 官方回调、授权码交换、身份签名验证、计划权限和保存等阶段。
- 首次失败的 HTTP 状态、安全错误码、响应形状和安全格式请求 ID。
- 可选：官方公开身份验证接口的 DNS/TLS/超时检查与响应时钟差。
- 新版有尚未过期的授权时，仅检查模型列表权限，不刷新或改动令牌。

报告不包含密钥、令牌、授权码、完整回调网址、邮箱、用户或工作区 ID、
本机用户路径、代理地址、会话想法、历史、原始日志或上游响应正文。
未知错误码和不符合安全格式的请求 ID 会隐藏。
报告只保存在本机，不自动上传。网络检查仅访问 OpenAI 官方授权/模型
列表接口，不调用模型，不消耗模型生成额度。取消勾选可只检查本机。

旧版没有保存失败阶段和上游错误码，诊断程序不能还原已经丢弃的细节。
这种报告会明确写“旧版详情缺失”；升级后再登录一次，才能精确定位。
检查公共接口成功不等于获准使用 ChatGPT 计划，也不证明实际生成成功。
程序不会把授权失败伪装成已连接，也不会绕过账户、工作区或地区限制。

只反馈诊断 JSON，不要发送 .env、api-key.json、chatgpt-auth.json、
完整回调地址、截图中的密钥或原始安装日志。
