Card Studio Windows 安装包

最简单的使用方法：

1. 解压整个 ZIP。
2. 双击“安装并启动.bat”。
3. 如果电脑没有 Node.js 22+，安装器会尝试使用 winget 自动安装。
4. 第一次运行会自动执行 npm install。
5. 浏览器会自动打开 http://localhost:8787。

以后再次使用，可以双击：
- 安装并启动.bat
或
- 启动卡牌工具.bat

AI 生图：
启动后在右侧“插画”区域填写 OpenAI API Key，并点击“保存 AI Key”。

不要只把 BAT 单独拖出文件夹运行；请保持整个 CardStudio 文件夹完整。
