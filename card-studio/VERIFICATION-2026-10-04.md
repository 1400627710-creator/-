# CardStudio 本轮修复与流程验证

验证日期：2026-10-04（UTC）。基于 Studio 3.0.0 Beta 5 私人源码与 Community 1.2.1 原始源码，交付 Studio **3.0.0 Beta 5.1** 和 Community **1.2.2**。

## 实际修复

| 问题 | 触发方式与原行为 | 修复结果 |
| --- | --- | --- |
| 当前卡组被无效导入清空 | Studio 打开格式正确但卡组为空的项目，提示失败后再次导出得到空卡组 | 在写入前校验，拒绝输入并保留当前卡组 |
| 锁定卡被批量修改 | Studio 批量命名仍改动锁定卡；源码中其他批量入口同样缺少保护 | 命名、编号、文字样式、皮肤、词条标记、清空插画和图片匹配跳过锁定卡 |
| 模板漂移计数误报 | 主模板更新后，锁定卡正确冻结，但精度面板仍统计其差异 | 冻结卡不计入继承漂移；普通跟随卡继续检查 |
| 启动异常横幅误显示 | 正常启动、没有运行错误时仍显示异常横幅 | 强制尊重 `hidden` 状态 |
| 社区版双击无法编辑 | 首次按下或单击时重建图层 DOM，浏览器无法把两次点击识别为双击 | 点击只更新选中状态；内容变动仍正常重绘 |
| 不同图片被错误去重 | 同名同尺寸图片的 Base64 前缀相同，第二张被丢弃 | 对比完整图片内容，两张均保留 |
| 素材累计超限静默丢弃 | 先导入 500 项，再导入 501 项，原程序显示成功但只留下 1000 项 | 拒绝整次超限合并，原 500 项及撤销历史保持完整 |

另外，快速检查改为“编辑通过 / 编辑警告 / 编辑错误”，明确完整项目检查仍负责文字溢出、安全区和裁切；常规自检补齐安全回归，ZIP 中文启动文件名恢复正常编码。

## 交付与接续

- Studio 私人更新包：`CardStudio-Studio-3.0.0-beta5.1-private.zip`，解压后双击 `安装并启动.bat`；已有 Node.js 22+ 可运行 `npm ci`、`npm start`。
- Community 更新包：`CardStudio-Community-1.2.2.zip`，解压后双击 `index.html` 即可使用。
- 原项目格式不升级。通过项目导出/打开功能迁移已有文件；原版本源码包保持保留。
- 公开 GitHub 在 `card-studio-community/` 同步 Community 1.2.2 源码、检查脚本和浏览器 CI；原 `card-studio/` 仍为 2.3.0 历史代码。
- Studio Beta 5.1 核心源码保持私有；公开仓库只记录其版本日志和验证结果。

下一阶段仍有代表卡变更前后预览、工作区收敛、素材来源与引用展示、语义版本记录和模块拆分等工作。本轮先完成稳定性修复，没有把这些设计待办写成已实现。
