# 卡牌组装流水线 1.0

面向没有美术和 PS 基础的桌游作者。它不是专业绘图软件，而是一条“选模板 → 填字段 → 选素材 → AI 插画 → 批量生产 → 打印导出”的卡牌组装流水线。

## 已完成的功能

### 模板
- 标准单位卡、法术卡、建筑卡、事件卡。
- 固定布局与自动排版，卡面文字可直接点击编辑。
- 可把现有模板另存为自定义模板，并选择保留哪些数值字段。
- 自定义模板仍使用锁定布局，不开放容易破坏版式的自由图层拖动。

### 素材与皮肤
- 边框：经典双线、极简细框、重甲粗框、仪式双框。
- 底纹：纯净、战术网格、斜纹、旧纸肌理。
- 费用标记：圆形、六角、菱形、方形。
- 稀有度标记：圆点、星标、宝石、刻线。
- 字体样式：现代、典籍、紧凑、柔和阅读。
- 素材支持分类、搜索、收藏、点击替换。
- 可上传自定义卡面图标、图片边框、图片底纹，并搜索、收藏、应用、删除。
- 颜色与组件组合可以保存成皮肤。
- 一键把当前皮肤应用到全部卡牌。

### 文字与变量
支持 {名称}、{费用}、{系别}、{攻击}、{血量}、{移速}、{射程}、{兵种}、{稀有度}。
文字自动换行，编辑时不会破坏布局。

### AI 插画
- 输入关键词生成当前卡牌插画。
- 生成结果自动 cover 裁切到插画区域。
- 重复点击即可重绘和替换。
- “整套统一风格”会应用于单张和批量 AI 生图。
- 可只给“缺图卡牌”顺序生成整套插画。
- API Key 只放在本机 .env，不写入网页代码。

### 批量生产
- CSV / XLS / XLSX / JSON 批量导入卡牌数据。
- 支持“模板 / template / 卡牌类型”字段自动分配模板。
- 多选图片批量导入：优先按“文件名 = 卡牌名称”匹配，剩余图片按顺序填充空卡。
- 可按搜索与模板筛选卡牌。
- 可按名称、费用、系别、稀有度、模板排序。
- 对当前可见卡牌批量命名。
- 导出 CSV / JSON 卡牌清单。
- 批量导出 PNG 并打包为 ZIP，ZIP 中同时附带 manifest.csv。

### 导出与打印
- PNG 300dpi。
- JPG 300dpi。
- 单张 PDF。
- A4 9 张拼版 PDF。
- 卡牌为 63×88mm 成品尺寸 + 四周 3mm 出血。
- PDF 带裁切线，可直接交给常规打印店继续处理。

### 项目管理
- 搜索、筛选、排序、新建、复制、删除。
- 撤销 / 重做。
- 本地自动保存。
- 本地版本快照与恢复。
- 项目保存为 .cardstudio 文件。
- 项目文件包括卡牌、皮肤、自定义模板、自定义图片素材和 AI 风格，可在其它电脑重新打开。
- 导入 / 导出清单。
- 一键清空全部插画。

## 最简单的 Windows 启动方法

1. 先安装 Node.js 18 或更高版本。
2. 下载或克隆整个仓库。
3. 打开 card-studio 文件夹。
4. 双击 **启动卡牌工具.bat**。
5. 第一次运行会自动安装依赖，之后会自动打开浏览器。

如果不使用 AI，以上步骤就足够。

## 开启 AI 生图

1. 把 .env.example 复制一份并改名为 .env。
2. 在 .env 中填写 OPENAI_API_KEY。
3. 再双击“启动卡牌工具.bat”。

## 手动启动

```bash
cd card-studio
npm install
npm start
```

浏览器访问 http://localhost:8787

## 自检

```bash
npm run check
```

这个命令会检查浏览器主脚本、服务端脚本和关键页面控件是否一致。GitHub Actions 也会在 card-studio 目录变化时自动执行同样的检查。
