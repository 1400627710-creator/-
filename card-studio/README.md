# 卡牌组装流水线 1.0

这是一个面向没有美术、排版和 Photoshop 基础的桌游作者的本地制卡工具。它不是专业绘图软件，而是一条：

**选模板 → 填字段 → 选素材/皮肤 → AI 插画 → 批量制卡 → 300dpi 打印导出**

的卡牌组装流水线。

## 已完成

### 1. 模板系统
- 内置标准单位卡、法术卡、建筑卡、事件卡。
- 布局锁定，用户只改内容，不会因拖动破坏版式。
- 不同模板自动显示对应数值字段。
- 可把现有模板另存为自定义模板，并选择攻击、血量、移速、射程等字段。
- 可删除自定义模板；内置模板受保护。

### 2. 文字编辑
- 卡面标题、费用、系别、类型、稀有度、效果和数值可直接点击修改。
- 右侧也提供表单式编辑。
- 支持变量：
  - {名称}
  - {费用}
  - {系别}
  - {攻击}
  - {血量}
  - {移速}
  - {射程}
  - {兵种}
  - {稀有度}
- 可分别设置标题、效果正文、系别/类型、数值、费用的字号、颜色、对齐与加粗。
- 当前区域文字样式可一键应用到全部卡牌。

### 3. 素材库与皮肤
内置可替换组件：
- 边框：经典双线、极简细框、重甲粗框、仪式双框。
- 底纹：纯净、战术网格、斜纹、旧纸肌理。
- 费用标记：圆形、六角、菱形、方形。
- 稀有度标记：圆点、星标、宝石、刻线。
- 字体：现代、典籍、紧凑、柔和阅读。

同时支持：
- 分类、搜索、收藏、点击替换。
- 上传自定义卡面图标、图片边框、图片底纹。
- 自定义素材可搜索、收藏、应用、删除。
- 保存当前颜色 + 组件组合为皮肤。
- 一键把当前皮肤和素材应用到全部卡牌。

### 4. AI 插画
- 页面内直接配置 OpenAI API Key，不需要手工编辑配置文件。
- API Key 只保存在本机的 `.env`，不会写入网页，也已被 Git 忽略。
- 支持 low / medium / high 三档生成质量。
- 输入关键词生成新图。
- “基于现图重绘”会使用当前插画作为输入图进行真正的图像编辑。
- 生成结果自动适配插画区域。
- 整套卡牌共享“统一风格”描述。
- 可只为缺图卡牌顺序批量生成 AI 插画。
- 不配置 AI Key 时，其它制卡功能仍可正常使用。

### 5. 批量制卡
支持导入：
- CSV
- XLS
- XLSX
- JSON

可识别中文和常用英文字段名，包括：
- 名称
- 费用
- 系别
- 卡牌效果
- 攻击
- 血量
- 移速
- 射程
- 兵种/类型
- 稀有度
- 关键词
- 模板 / template / 卡牌类型

批量工具：
- 多选图片批量导入。
- 优先用“图片文件名 = 卡牌名称”自动匹配。
- 未匹配图片按顺序填入剩余空卡。
- 按搜索、模板筛选。
- 按名称、费用、系别、稀有度、模板排序。
- 对当前可见卡牌批量编号命名。
- 一键清空全部插画。
- 导出 CSV / JSON 卡牌清单。

### 6. 导出与打印
- 单张 PNG 300dpi。
- 单张 JPG 300dpi。
- 单张 PDF。
- A4 九宫格拼版 PDF。
- 批量 PNG 打包 ZIP。
- ZIP 内附带 manifest.csv 清单。
- 卡牌成品尺寸：63 × 88 mm。
- 四周 3 mm 出血，导出画布为 69 × 94 mm。
- PDF 带裁切标记。

### 7. 项目管理
- 卡牌集搜索、筛选、排序。
- 新建、复制、删除。
- 撤销 / 重做。
- 本地版本快照与恢复。
- 自动保存。
- 完整项目使用 IndexedDB 保存，能够容纳 AI 图片和上传素材，不再受 localStorage 小容量限制。
- 可保存为 `.cardstudio` 项目文件并在其它电脑打开。
- 项目文件包含卡牌、皮肤、自定义模板、自定义素材和 AI 风格设置。

## Windows 最简单启动方法

### 第一次使用
1. 安装 **Node.js 22 或更高版本**。
2. 下载或克隆整个仓库。
3. 打开 `card-studio` 文件夹。
4. 双击 **启动卡牌工具.bat**。
5. 第一次启动会自动安装依赖。
6. 浏览器会自动打开：
   `http://localhost:8787`

以后再次使用，只需要双击 **启动卡牌工具.bat**。

启动脚本会自动检查 Node.js 是否存在、版本是否达到 22。

## AI 第一次设置

启动工具后，在右侧 **插画** 区域找到：

**AI Key（只保存在本机）**

粘贴 OpenAI API Key → 点击 **保存 AI Key**。

之后不需要重复填写。

高级用户仍可以手动复制 `.env.example` 为 `.env` 来配置。

## 手动运行

```bash
cd card-studio
npm install
npm start
```

浏览器打开：

```text
http://localhost:8787
```

## 自动检查

本地执行：

```bash
npm run check
```

检查内容包括：
- 浏览器主脚本语法。
- 本地服务端语法。
- 关键 UI 控件是否存在。
- 关键按钮是否存在处理逻辑。
- IndexedDB、AI Key 设置、AI 重绘等核心功能是否接入。

GitHub Actions 会在 `card-studio` 代码变化后自动执行同一套检查。

## 安全说明

- `card-studio/.env` 已加入 `.gitignore`。
- `card-studio/node_modules/` 已加入 `.gitignore`。
- AI Key 不会被写入项目导出文件。
- `.cardstudio` 项目文件会包含卡牌图片和用户上传素材，因此它可能比较大，这是正常现象。
