# 卡牌组装流水线

面向没有美术和 PS 基础的桌游作者。产品不是专业绘图软件，而是“卡牌组装流水线”。

核心操作：

**选模板 → 填字段 → 选择可复用素材 → AI 生成插画 → 实时预览 → 批量导入 → 300dpi 导出**

## 当前版本：MVP 第二阶段

### 模板系统

已经提供 4 类锁定模板：

- 标准单位卡：攻击、血量、移速、射程。
- 法术卡：威力、射程，效果区扩大。
- 建筑卡：火力、耐久、射程。
- 事件卡：大文本区，无战斗数值。

模板布局锁定。用户只能改内容，不会因为拖动破坏排版。

### 素材复用

素材已经拆为独立组件：

- 边框：经典双线、极简细框、重甲粗框、仪式双框。
- 底纹：纯净、战术网格、斜纹、旧纸肌理。
- 费用标记：圆形、六角、菱形、方形。
- 稀有度标记：圆点、星标、宝石、刻线。
- 字体风格：现代无衬线、典籍衬线、紧凑标题、柔和阅读。

素材库支持分类、搜索、收藏、点击替换。颜色和组件组合可以保存为“皮肤”，并可一键应用到全部卡牌。

### 文字与变量

卡面文字可以直接点击编辑，也可以在右侧表单中修改。支持：

{名称}、{费用}、{系别}、{攻击}、{血量}、{移速}、{射程}、{兵种}、{稀有度}

### AI 插画

右侧输入关键词和整套统一风格，通过本地服务端调用 OpenAI 图像接口。生成结果自动进入插画区域并裁切适配。

API Key 只放在本机 .env，不写入浏览器页面。

### 批量制卡

支持 CSV / XLS / XLSX / JSON。模板列可以使用：

模板 / template / 卡牌类型

中文模板名称“单位、法术、建筑、事件”可自动识别。

常用字段：

名称, 费用, 系别, 卡牌效果, 攻击, 血量, 移速, 射程, 兵种, 稀有度, 关键词

### 导出与打印

- PNG 300dpi
- JPG 300dpi
- 单张 PDF
- A4 九宫格批量 PDF
- 63×88mm 成品尺寸
- 四周 3mm 出血
- 裁切线

### 项目管理

- 卡牌搜索
- 新建、复制、删除
- 撤销 / 重做
- 本地自动保存
- 本地版本快照与恢复
- 一键全项目换肤

## 运行

1. 安装 Node.js 18 或更高版本。
2. 进入 card-studio 文件夹。
3. 执行 npm install。
4. 执行 npm start。
5. 浏览器打开 http://localhost:8787。

AI 生图需要把 .env.example 复制为 .env，并填写 OPENAI_API_KEY。不配置时其它功能照常使用。

## 下一阶段建议

- 自定义模板编辑器：允许定义“字段”，但仍不开放自由图层拖拽。
- 图标与图片素材上传后保存到项目素材库。
- 批量命名和导出清单。
- 批量换图 / AI 生图队列。
- 项目文件导入导出，让项目可以在不同电脑迁移。
- 印厂预设与更多拼版规格。
