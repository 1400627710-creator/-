# 卡牌组装流水线 MVP

这是一个面向没有美术和 PS 基础的桌游作者的卡牌制作工具。

核心操作：选模板 → 填字段 → 选皮肤/素材 → AI 生成插画 → 实时预览 → 批量导入 → 300dpi 导出。

## 当前 MVP 已实现

- 锁定式“标准单位卡”模板。
- 固定区域：标题、费用、系别、插画、效果、攻击、血量、移速、射程、兵种、稀有度、关键词。
- 卡面直接点击编辑；布局不可拖乱。
- 变量：{名称}、{费用}、{攻击}、{血量}、{移速}、{射程}、{系别}、{兵种}、{稀有度}。
- 可复用皮肤：搜索、收藏、应用、改色、保存。
- AI 插画生成并自动适配卡牌插画区域。
- CSV / XLS / XLSX / JSON 批量导入。
- PNG / JPG / 单张 PDF / A4 九宫格批量 PDF。
- PDF 以 63×88mm 成品尺寸 + 四周 3mm 出血生成，并带裁切标记。
- 卡牌集搜索、新建、复制、删除、本地自动保存。

## 运行方法

1. 安装 Node.js 18 或更高版本。
2. 进入 card-studio 文件夹。
3. 运行 npm install。
4. 复制 .env.example 为 .env。
5. 如果要使用 AI 生图，在 .env 里填写 OPENAI_API_KEY。
6. 运行 npm start。
7. 浏览器打开 http://localhost:8787。

不配置 API Key 时，除 AI 生图外的功能仍然可用。

## 批量数据字段

中文列名可以使用：

名称, 费用, 系别, 卡牌效果, 攻击, 血量, 移速, 射程, 兵种, 稀有度, 关键词

也兼容对应的常见英文字段名。
