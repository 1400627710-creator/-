# 卡递 1.0.0 · 完整版

高效、共创、简洁。以你提供的原始 CardStudio 3.0.0-beta6 为基础，完整保留制卡、模板、素材、词条、打印、批量导出、TTS 和 AI 接入功能。

## 开始使用

解压后双击 **启动卡递.bat**。如果这台电脑尚未装运行环境，双击 **安装并启动.bat**；安装完成会自动打开卡递。不需要 ChatGPT、Google、Apple 或其他平台账号。本机始终拥有完整管理能力，首次联网时自动启用共享仓库管理。

顶部只有两个资料入口：**词条库**、**素材库**。进入后默认是 **我的**；切到 **共享** 查看伙伴可以取用的资料。

- 词条选中后点击“插入卡牌”；完整定义、示例与设计说明保留在项目里。
- 素材选中后点击“放到卡面”；卡框会设为卡框，图标设为图标，插画设为插画，底纹设为底纹，卡背设为项目默认卡背。
- 点击“共享”即可直接发布。批量共享只需勾选资料后点击“共享所选”。
- “待审核”查看伙伴投稿，可以发布并收录、给出补充反馈或暂不采纳。
- “管理”调整浏览与投稿范围、邀请预审、撤销授权、保存恢复凭证、备份和恢复资料。

## 原有词条与项目

先关闭旧版，再打开卡递。默认仍用 `http://localhost:8794` 和原浏览器保存键，从旧保存增量收录，不清空全局词条。

如果旧程序占用了这个地址，新启动器会明确提示。可以关闭旧版再启动卡递，或把旧版导出的 `.cardstudio` 文件直接打开；不需要逐个复制词条。

你提供的程序包没有包含浏览器里实际保存的词条。本次没有用示例词条代替原设计。第一次读取原保存或打开旧项目时，会保存原有完整词条并直接共享有效定义；没有填写定义的草稿会留在“我的”，补好后点“共享”即可。

“我的”资料保存在电脑的独立卡递资料目录；换解压目录或使用不同端口不会清空它。空项目不会删除资料。原图保持原始字节，共享图片使用去除元数据的 PNG 副本。同名不同定义分别保留，回收站可恢复。

项目自己保留所用词条和图片的快照。共享库变化不会自动改动已经制作的卡牌；主动采用同名不同定义时，需要确认更新本项目快照。锁定卡牌仍受原来的保护。

已经收录并上线四份你原先制作的透明卡框，以及 GitHub 规则 v0.4 中明确写出的“再生”词条。词条注明真实来源与待确认问题，未把示例或尚未定义的机制冒充原设计。

## 自检与备份

双击 **自检.bat**，或运行 `npm run check`。共享管理页可下载包含原图与共享历史的完整备份；默认恢复增量收录到本机，不覆盖当前项目和共享库。设备恢复凭证单独保存，普通资料备份不含管理授权。

本次自检的行为、界面和线上结果见 `verification/kadi/` 与《卡递-自检与交付记录.md》。测试环境为 Linux、Node.js 24 与 Chromium；Windows 原生启动和国内 QQ/微信内置浏览器网络没有实机验证。

首次安装授权有效一年、仅能使用一次；启用后设备授权独立保存在本机资料目录，重复解压或更新不需要再次启用。另一台电脑从“管理→授权另一台管理电脑”添加即可。

程序包中旧版 CHANGELOG 是历史记录；当前使用说明以本文为准。
