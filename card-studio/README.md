# 卡牌组装流水线 1.0

这是一个面向没有美术和 PS 基础的桌游作者的本地卡牌制作工具。定位不是专业绘图软件，而是：

**选模板 → 填字段 → 选可复用素材 → AI 生成/重绘插画 → 实时预览 → 批量制卡 → 印刷导出**

布局、对齐、安全区和打印尺寸由系统管理，用户不需要理解图层。

## 已完成

### 模板
- 内置：标准单位卡、法术卡、建筑卡、事件卡。
- 卡面布局锁定，文字自动换行，不能通过拖动破坏版式。
- 可把任意模板另存为自定义模板，并选择保留攻击、血量、移速、射程等字段。
- 自定义模板仍沿用锁定版式。

### 素材与皮肤
- 内置边框、底纹、费用标记、稀有度标记、字体风格。
- 素材支持分类、搜索、收藏、点击替换。
- 可上传自定义卡面徽记、透明图片边框、图片底纹。
- 主题颜色可直接改色。
- 当前组件 + 颜色可保存成皮肤。
- 一键将当前皮肤应用到整套卡牌。

### 文字编辑
- 点击卡面区域直接输入。
- 右侧表单同步编辑。
- 标题、效果正文、元信息、数值、费用可分别调整字号、颜色、对齐和粗体。
- 字体风格从素材库切换。
- 支持变量：{名称}、{费用}、{系别}、{攻击}、{血量}、{移速}、{射程}、{兵种}、{稀有度}。

### AI 插画
- 输入关键词生成新插画。
- 生成后自动 cover 裁切到插画区。
- 可选择快速 / 中等 / 高质量。
- 可基于当前插画进行真正的 AI 重绘，而不是简单重新生成。
- “整套统一风格”提示会用于单张和批量 AI。
- 可为全部缺图卡牌按顺序批量生成。
- 页面内可保存本机 API Key；服务只监听 127.0.0.1。
- 新图模型默认：gpt-image-2.5-flare。
- 重绘模型默认：gpt-image-2.5-sunburst。

### 批量制卡
- CSV / XLS / XLSX / JSON 导入。
- 数据可指定单位 / 法术 / 建筑 / 事件模板。
- 多选图片批量换图：优先按“文件名 = 卡牌名称”匹配，剩余图片按顺序填入缺图卡牌。
- 按搜索、模板、系别、稀有度筛选。
- 按名称、费用、系别、稀有度、模板排序。
- 对当前筛选结果批量命名。
- 导出 CSV / JSON 清单。
- 当前筛选结果可批量导出 PNG ZIP 或 JPG ZIP，压缩包内附 manifest.csv。

### 导出与打印
- 当前卡 PNG 300dpi。
- 当前卡 JPG 300dpi。
- 当前卡 PDF。
- A4 / A3 / Letter 自动拼版 PDF。
- 成品尺寸：63 × 88 mm。
- 四周出血：3 mm。
- 实际输出卡面：69 × 94 mm。
- 裁切线可开关。
- 拼版自动计算当前纸张每页可放数量。

### 项目管理
- 项目名称。
- 搜索、筛选、排序、新建、复制、删除。
- 撤销 / 重做。
- IndexedDB 自动保存完整项目，包括大体积插画。
- 本地版本快照与恢复。
- 导出 / 打开 .cardstudio 项目文件。
- 项目文件包含卡牌、图片、皮肤、自定义模板、自定义素材、AI 风格和打印设置。
- 清空全部插画。

## Windows：最简单的启动方法

1. 安装 Node.js 22 或更高版本。
2. 下载或克隆整个仓库。
3. 打开 `card-studio` 文件夹。
4. 双击 **启动卡牌工具.bat**。
5. 第一次启动会自动执行 `npm install`，随后自动打开浏览器。

以后仍然双击同一个文件即可。

不使用 AI 时，安装依赖以后即使浏览器无法访问 CDN，制卡、数据导入、图片导出、PDF 和 ZIP 仍使用本地依赖工作。

## AI Key

页面的“插画”区域可以直接填写并保存 API Key，也可以手动：

1. 把 `.env.example` 复制为 `.env`。
2. 填入 `OPENAI_API_KEY`。
3. 重启工具。

API Key 写入本机 `.env`，不会进入卡牌项目文件。

## 批量数据

示例：`public/sample-cards.csv`

支持列：

`模板, 名称, 费用, 系别, 卡牌效果, 攻击, 血量, 移速, 射程, 兵种, 稀有度, 关键词, 插画关键词`

模板可以填写：`单位`、`法术`、`建筑`、`事件`。

## 数据与备份

- 日常编辑：自动保存到浏览器 IndexedDB。
- 关键节点：使用“版本快照”。
- 跨电脑 / 长期备份：使用顶部“保存项目”，得到 `.cardstudio` 文件。
- 项目文件包含图片，因此可能较大。

## 手动启动

```bash
cd card-studio
npm install
npm start
```

浏览器打开：`http://localhost:8787`

## 自检

```bash
npm run check
```

自检覆盖：主脚本语法、关键 DOM、事件处理、浏览器依赖、本地静态库、IndexedDB、AI 接口、项目功能、打印设置。GitHub Actions 会在 `card-studio/**` 变化时自动执行同一检查。
