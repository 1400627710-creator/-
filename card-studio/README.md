# 卡牌组装流水线 2.3

这是一个面向没有美术和 PS 基础的桌游作者的本地卡牌制作工具。定位不是专业绘图软件，而是：

**选模板 → 填字段 → 选可复用素材 → 规划/导入插画 → 自由精调 → 实时预览 → 批量制卡 → 印刷导出**

普通制卡模式下，布局、对齐、安全区和打印尺寸由系统管理；自由布局模式则提供清晰的图层面板给需要精调的用户。

## 已完成

## 2.3 编辑器架构升级

- 右侧工具改为 6 个工作区：内容、文字、自由编辑、视觉、规则/卡查、导出/项目，减少长页面滚动与功能混杂。
- 自由编辑支持框选、Ctrl/Cmd 多选、整组选区移动与缩放、锁定比例、六向对齐、水平/垂直等距分布和智能吸附参考线。
- 新增键盘工作流：L 切换自由编辑；1~6 切换工作区；方向键三级微调；Ctrl/Cmd+A 全选；Ctrl/Cmd+D 复制；Q/E 旋转；[ / ] 调层级；Delete 删除/隐藏；Esc 清空选择。
- 双击自定义文字可直接编辑；双击卡面空白处可立即新增文字。
- 皮肤与素材/卡框彻底解耦：切换皮肤或“应用到全部”只同步主题样式，不再覆盖透明卡框、背景素材、插画焦点或自由布局。
- 私人开发版已移除 AI Key、登录、验证、外部 AI 服务调用和相关 SDK 依赖；当前仅保留高质量 AI 绘画提示词规划器。
- 提示词规划器会自动组合卡名、类型、系别、画风、卡牌构图安全区和“禁止文字/UI”等约束，并支持生图提示词与重绘提示词一键复制。
- 保留“全幅插画 · 竞技卡”和“古典双槽 · 边框卡”两套成品版式、智能卡框导入、插画焦点/缩放与自动配色。
- 系列名 / 编号 / 年份 / 署名仍作为正式独立图层与导出数据字段。
- 自定义卡框保持最高优先级，不会因皮肤切换而被系统边框替换。


### 模板
- 内置：标准单位卡、法术卡、建筑卡、事件卡。
- 默认普通制卡模式保持稳定版式；切换“自由布局”后，名称、系别、类型、稀有度、费用、效果、攻击、血量、移速、射程、标签和插画全部成为独立模块，可分别拖动、缩放、旋转、排序、锁定、隐藏和调透明度。
- 可把任意模板另存为自定义模板，并选择保留攻击、血量、移速、射程等字段。
- 自定义模板可继续使用普通模式，也可进入自由布局精调。

### 素材与皮肤
- 内置边框、底纹、费用标记、稀有度标记、字体风格。
- 素材支持分类、搜索、收藏、点击替换。
- 可上传自定义卡面徽记、透明图片边框、图片底纹。
- 主题颜色可直接改色。
- 当前组件 + 颜色可保存成皮肤。
- 一键将当前皮肤应用到整套卡牌。
- 新增“古典花饰线框”“油画画布纹”“古典书卷体”和“古典花饰典藏”整套皮肤；边框使用原创对称植物卷草线描。
- 自由布局可直接导入 PNG / JPG / WebP / SVG 小素材；新图片默认位于文字层下方，并可通过图层面板上移/下移/置顶/置底。图标可附加中央/上下/左右文字。

### 文字编辑
- 点击卡面区域直接输入。
- 右侧表单同步编辑。
- 标题、效果正文、元信息、数值、费用可分别调整字号、颜色、对齐和粗体。
- 字体风格从素材库切换。
- 支持变量：{名称}、{费用}、{系别}、{攻击}、{血量}、{移速}、{射程}、{兵种}、{稀有度}。
- 支持规则词条：选中文字建立彩色词条、自动识别已知词条、词条说明仓库、反查使用卡牌。

### AI 插画规划
- 当前私人版不直连外部 AI 服务，也不要求任何 Key、账户登录或验证。
- 输入本张画面要求，并选择“高端幻想概念厚涂 / 动漫墨线厚涂 / 古典幻想油画 / 史诗抽象笔触”等画风。
- 工具会根据当前卡牌名称、类型、系别和规则语义自动生成完整的竖版卡牌插画提示词。
- 提示词会自动加入顶部标题安全区、底部规则安全区、明确主体轮廓，以及禁止文字、Logo、UI、水印等约束。
- 可一键复制“生图提示词”或“基于现图重绘提示词”，生成完成后把图片直接上传回卡牌。
- 已上传插画仍支持焦点 X/Y、缩放和自动配色，不依赖任何外部 AI 服务。


### 批量制卡
- CSV / XLS / XLSX / JSON 导入。
- 数据可指定单位 / 法术 / 建筑 / 事件模板。
- 多选图片批量换图：优先按“文件名 = 卡牌名称”匹配，剩余图片按顺序填入缺图卡牌。
- 按搜索、模板、系别、稀有度筛选。
- 按名称、费用、系别、稀有度、模板排序。
- 对当前筛选结果批量命名。
- 导出 CSV / JSON 清单。
- 当前筛选结果可批量导出 PNG ZIP 或 JPG ZIP，压缩包内附 manifest.csv。

### 卡查与 TTS
- 标签化卡查可按编号、名称、类型、系别、稀有度、标签、规则关键词和效果检索。
- 卡查联动规则词条定义，可从词条定位相关卡牌。
- TTS 导出包含卡牌索引与 `glossary.json` 词条数据，为后续 Steam Tabletop Simulator 模组接入保留结构。

### 导出与打印
- 当前卡 PNG 300dpi。
- 当前卡 JPG 300dpi。
- 当前卡 PDF。
- A4 / A3 / Letter 自动拼版 PDF。
- 成品尺寸：63 × 88 mm。
- 四周出血：3 mm。
- 实际输出卡面：69 × 94 mm。
- 裁切线可开关。
- 拼版自动计算当前纸张每页可放数量。

### 项目管理
- 项目名称。
- 搜索、筛选、排序、新建、复制、删除。
- 撤销 / 重做。
- IndexedDB 自动保存完整项目，包括大体积插画。
- 本地版本快照与恢复。
- 导出 / 打开 .cardstudio 项目文件。
- 项目文件包含卡牌、图片、皮肤、自定义模板、自定义素材、AI 风格和打印设置。
- 清空全部插画。

## Windows：最简单的启动方法

1. 安装 Node.js 22 或更高版本。
2. 下载或克隆整个仓库。
3. 打开 `card-studio` 文件夹。
4. 双击 **启动卡牌工具.bat**。
5. 第一次启动会自动执行 `npm install`，随后自动打开浏览器。

以后仍然双击同一个文件即可。

当前 2.3 私人版的制卡、数据导入、卡框处理、图片导出、PDF、ZIP 和 AI 提示词规划均在本地工作，不依赖外部 AI 服务。

## 私人版 AI 接入说明

当前版本不包含 AI Key、账户登录、验证、外部 AI API 调用或相关 SDK。未来若重新设计一体化生图，会作为独立连接层处理，不与制卡编辑流程耦合。


## 批量数据

示例：`public/sample-cards.csv`

支持列：

`模板, 名称, 费用, 系别, 卡牌效果, 攻击, 血量, 移速, 射程, 兵种, 稀有度, 关键词, 插画关键词`

模板可以填写：`单位`、`法术`、`建筑`、`事件`。

## 数据与备份

- 日常编辑：自动保存到浏览器 IndexedDB。
- 关键节点：使用“版本快照”。
- 跨电脑 / 长期备份：使用顶部“保存项目”，得到 `.cardstudio` 文件。
- 项目文件包含图片，因此可能较大。

## 手动启动

```bash
cd card-studio
npm install
npm start
```

浏览器打开：`http://localhost:8787`

## 自检

```bash
npm run check
```

自检覆盖：主脚本语法、关键 DOM、事件处理、自由布局、图文组件、规则词条、卡查/TTS、古典视觉组件、AI 美术方向、浏览器依赖、本地静态库、IndexedDB、项目功能、打印设置。GitHub Actions 会在 `card-studio/**` 变化时自动执行同一检查。
