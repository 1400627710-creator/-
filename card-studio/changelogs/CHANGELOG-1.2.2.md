# CardStudio Community 1.2.2

本轮基于 1.2.1 原始源码修复实际交互与素材导入问题，`.cscard` 保持 v3，继续读取 v1/v2。

## 修复

- 单击和普通模式的按下事件只更新选中状态，保留原 DOM，让浏览器能识别连续两次点击并打开文字编辑器。
- 新增、复制、隐藏/删除等内容变动仍完整重绘，避免双击修复影响图层显示。
- 素材去重比较完整图片数据；同名、同尺寸、Base64 前缀相同但内容不同的图片均保留。
- 多次素材导入合并后超过 1000 项时，拒绝整次操作并保留原素材库，不再静默丢弃尾部素材。
- 本地图片批量加入同样先校验合并数量和 120MB 总量，不再按剩余容量静默截断选择文件。
- 补齐普通 `userAssets` 输入的 Studio 素材角色映射。
- 修正 Windows 便捷入口在 ZIP 内的中文文件名编码。

## 回归检查

- `npm run check`：语法、启动契约、运行行为、安全稳定性与共享素材契约。运行行为新增原生点击目标保护、真实 PNG 去重、累计超限保留及撤销历史验证。
- `npm run check:browser`：真实 Chromium 验证双击编辑、立即保存、项目重开/刷新、新增图层/撤销、1380×1880 PNG、不同图片保留、累计超限保护及离线无网络导出。
- 两版 `.csassets` 往返、分类映射和重复导入通过。

直接双击 `index.html` 仍可使用，不需要 Node 或 npm。开发检查的依赖只用于开发和持续集成。
