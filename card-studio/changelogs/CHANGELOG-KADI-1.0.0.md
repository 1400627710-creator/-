# 卡递 1.0.0 · 2026-10-05

以用户提供的原始完整版为基础，取消社区制卡编辑器计划，正式改名“卡递”。设计目标始终是高效、共创、简洁。

- 保留原版全部制卡、模板、打印、批量导出、TTS、项目保护与 AI 接入；本机完整权限无需登录。
- 顶部新增词条库、素材库，默认“我的”，共享内容和审核放在同一界面。
- 新增独立本机资料库，旧保存与旧项目增量收录，空项目不清空资料，同名不同定义分别保留。删除进回收站，项目快照保持独立。
- 发布免账号的伙伴资料入口：浏览下载免登录，投稿只填昵称，可保存凭证找回投稿与审核反馈。
- 完整版直接共享、审核并收录；限定类别预审、邀请、暂停投稿、下架恢复、历史回滚、备份与设备撤销都在管理入口。
- 管理凭证留在本机服务，首次设备启用自动完成；本次前端共享服务和公开仓库不再加入完整版核心与管理密钥；曾经公开的旧代码仍可能存在于 Git 历史。
- 图片真实解码后重新编码，共享副本去除附加元数据，透明度保留，本机原图不改动。
- 已发布用户四份原透明卡框与规则 v0.4 的“再生”词条。“再生”注明来源和原规则尚待确认的细节。

两轮自检修复了重复收录、回收站内容重新出现、词条引用前多余空格、服务器 PNG 解码兼容和素材预览宽度为零、同名投稿收录错副本和大备份单次提交过大的问题。原功能检查、9 项本机行为、19 项共享服务行为、14 项界面流程、真实线上互通及四份图像像素检查均有记录。

旧浏览器里的完整词条不在用户上传的程序包中，不能声称全部恢复。新版本会从原保存和旧项目中收录并共享有效原定义，草稿保留在“我的”。Windows 原生启动与国内 QQ/微信网络尚未实机验证。
