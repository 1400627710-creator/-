# CardStudio 3.0.0 Beta 5 — 专业工作台收敛第一阶段

Beta 5 不追求增加功能数量，而是把已经存在的专业能力变得更安全、更早反馈、更容易理解。

## 1. 持续卡牌 QA

舞台右上角新增当前卡牌质量状态：

- 通过
- 警告
- 错误
- 锁定 · 通过 / 警告 / 错误

它使用轻量快速检查持续更新，包括编号冲突、词条 / 图标引用、插画 DPI、字段约束、卡名中轴与模板继承漂移等。点击状态可直接打开完整项目检查中心；精确 DOM 安全区 / 裁切 / 文字溢出仍由完整 Preflight 负责。

## 2. 类型模板影响预览

以下高影响操作不再直接批量传播：

- “设为此类型统一布局”
- 数值徽章按毫米写入类型模板
- 布局组件写入当前类型主模板

在真正应用之前，Studio 会显示：

- 同类型卡牌数量
- 会自动跟随的卡牌数量
- 存在局部覆盖的卡牌数量
- 已锁定并冻结的卡牌数量
- 发生变化的语义模块
- 优先需要复核的代表卡

## 3. 锁定卡真正冻结

过去类型模板更新会绕过卡牌锁定，导致已锁定卡仍可能被主模板批量改版。Beta 5 修正为：

- 锁定卡不会被 `applyTemplateMaster()` 改动。
- 锁定期间因主模板继续演进产生的几何差异，不再被误判成“继承漂移”。
- 解锁后仍可通过模板校准 / 下一次模板同步重新跟进最新版式。

这使“锁定”真正具备发布冻结语义。

## 4. 性能约束

持续 QA 使用 120ms 合并刷新，不在布局拖动的每个 pointermove 上同步扫描整个项目，避免大项目下明显拖慢自由布局。

## 5. 新增回归检查

新增 `beta5-safety-check.mjs`，专门验证：

- 持续 QA UI 与逻辑存在
- 模板高影响入口不会绕过影响预览
- 锁定卡模板冻结契约
- 快速检查 / 完整 Preflight 不会把锁定冻结误报成漂移
