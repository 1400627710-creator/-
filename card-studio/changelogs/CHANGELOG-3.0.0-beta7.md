# Studio 3.0.0-beta7

2026-10-05，北京时间。与 Community 1.4.0 及线上公共资料仓库配套。

Beta 6 的共享数据只写入本机 shared-data；它没有完成独立电脑和独立社区版本之间的在线互通。本版更正该设计和此前交付声明。

- 顶部直接显示“词条库”和“素材库”，两者都有“公共 / 我的 / 待审核”。私人版原来的项目素材管理保留。
- 私人版支持发布完整词条设计，支持将我的词条批量发布；图片支持直接发布原文件和说明。
- 社区词条、图片均进入同一线上待审核区。私人版可预览、先加入我的资料、采用并发布或不采用；公开内容保留投稿作者署名。
- 一次登录连接管理员；管理凭据保存在本机服务端，不进入社区前端和制卡项目。可在资料库断开管理连接。
- 公共数据和图片由持久化线上仓库保存。换电脑和重新部署不会依赖原来的私人电脑是否开机。
- 同名更新校验版本；冲突不覆盖已发布设计。重复提交幂等。词条、素材仅上传公开字段，私人项目及 AI 密钥不上传。
- 已采用内容保存到本地项目；后台仓库更新不自动替换作品中的词条和图片。断网保留缓存并明确提示错误。
- Windows 启动器先检查健康接口与准确版本；旧服务占用默认端口时选择空闲端口，避免误打开 Beta 5/6 页面。
- 修复刷新清除操作成功提示、登录跳转丢失投稿选中状态，并从生产代码移除测试管理员通道。

首次使用：启动新版，打开顶部词条库，点击“连接管理员”并登录仓库管理员账号；进入“我的”，发布选中的词条或“发布全部词条”。社区版会从线上仓库读取实际发布内容。已有词条属于原项目时，先打开该 .cardstudio 项目。

已完成服务检查、独立客户端浏览器流程、生产 HTTP、重新部署持久化和启动回归检查。真实 ChatGPT 登录点击流程与 Windows 原生 BAT 执行未在当前环境运行，详见配套自查记录。
