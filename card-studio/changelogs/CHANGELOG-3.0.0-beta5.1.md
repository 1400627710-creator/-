# CardStudio Studio 3.0.0 Beta 5.1

本轮基于私人版 Beta 5 原始源码修复实际流程问题，项目 Schema 保持 v20。

## 修复

- 正常启动时，隐藏的运行异常横幅不再被 `display:flex` 错误显示；全部 `hidden` 元素统一遵守隐藏状态。
- 模板精度面板不再把锁定卡与新主模板之间的冻结差异统计为继承漂移。
- 批量命名、编号、文字样式、皮肤、自动词条标记、清空插画和批量图片匹配跳过锁定卡；被锁定卡使用的自定义模板不能删除。
- 项目导入先校验格式、版本、非空卡组和关键容器类型，再写入项目；已覆盖的无效输入不会清空当前卡组或添加无效撤销步骤。
- 舞台快速检查明确显示“编辑通过 / 编辑警告 / 编辑错误”，提示发布前需要运行完整项目检查。
- 常规 `npm run check` 与一键自检均包含 Beta 5 安全检查和新增工作流行为回归。
- 修正 ZIP 中中文启动脚本的文件名编码，并统一当前运行版本标识。

## 验证

- 语法、核心契约、共享素材桥、AI 本地模拟、模板安全和工作流行为回归通过。
- 真实 Chromium 验证制卡、自动保存与项目重开、815×1110 PNG、模板预览取消/确认/撤销、锁定保护、无效导入保护、完整检查阻止错误发布和单张 69×94mm PDF。
- 与 Community 的 `.csassets` 往返及重复导入通过；私人素材只在明确标记为共享后进入共享导出。

本轮没有调用付费 AI 服务；Windows 启动脚本保持 CRLF 并检查打包文件名，未在 Windows 真机执行。私人版核心源码继续保持私有。
