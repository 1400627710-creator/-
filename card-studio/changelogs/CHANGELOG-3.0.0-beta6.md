# CardStudio Studio 3.0.0 Beta 6

更新日期：2026-10-05（北京时间）

本版让 Studio 与 Community 共用持久词条仓库，并把词条的设计信息完整带到社区版。项目格式仍为 v20。

- 词条增加检索别名、使用示例与设计说明；共享导出保留名称、颜色、分类、标签和完整定义。
- 新增“发布到两版词条仓库”“打开社区版”和“下载含词条的社区版”。正式词条写入本机 `shared-data/glossary.json`，重启后保留。
- 安装包自带独立 Community 1.3.0；本地同源运行时直接读取正式词条，离线下载包包含当前已发布快照。
- 社区投稿写入独立待审核队列，重复投稿去重，不直接修改正式仓库。
- 导入或接收投稿先显示原设计与待合并内容。新增默认勾选，冲突默认保留原设计；取消不修改词条或消费投稿。
- 锁定卡仍引用旧名称时拒绝改名；异常词条在改动当前项目之前拒绝。
- 共享格式严格限制 ID、名称、字段长度、5000 个词条及 5MB 文件；白名单排除卡牌、素材、密钥和私人项目结构。
- 发布使用修订号避免并发覆盖；落盘使用临时文件和替换；修改接口限制本机同源 JSON 请求。
- 一键自检增加两版词条仓库和投稿审核保护检查，词条窗口按钮改为横向换行。

验证：两版常规自检、Studio 一键诊断通过；原有浏览器流程 11/11、社区独立浏览器回归 4/4、词条互通浏览器流程 6/6 通过。包括发布、完整设计查看、刷新/项目携带、投稿审核、冲突保留、锁定改名保护、离线包与重启持久化。详见 `VERIFICATION-2026-10-05.md`。
