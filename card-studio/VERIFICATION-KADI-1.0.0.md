## 真实资料

已上线四份用户原始透明卡框：象牙黑饰边、维多利亚玫瑰、复古玫瑰、玫瑰卷轴。完整版保留原文件字节，共享服务使用安全重编码的 PNG；线上取回后逐像素对比，颜色与透明度完全一致。

已上线一个明确来源的词条“再生”，来自用户 GitHub《添加规则 v0.4》第八节。原文定义为死亡后回到手牌并变为初始状态；原规则仍未确认是否占手牌上限、是否消耗费用，词条设计说明保留这一问题，没有编造机制。

初始线上目录为 **1 个真实词条、4 份真实素材**。用户上传的程序 ZIP 不包含其原浏览器中实际保存的完整词条和项目，不能声称它们已经全部恢复。新版仍使用原保存键和默认地址，从旧保存与旧项目增量收录有效原定义，再分批直接共享；没有定义的草稿保留在“我的”。旧项目复用同一编号但定义不同，也会保留两个副本。原有素材增量收录到“我的”，需要分享时直接点击“共享”。

## 第二轮修复

1. 导入没有词条字段的旧项目，不再默认清空词条；明确为空的项目也不能清空独立资料库。
2. 素材预览宽度为零的问题修复；透明卡框在原版布局中真实可见。
3. 自动收录不再使回收站资料重新出现；相同内容、不同来源与署名可分别保留。
4. 同名投稿按实际发布编号收录；采用共享新修订返回正确副本，旧定义不被悄悄覆盖。
5. 实际从备份重新收录删除的词条；当前卡牌与云端目录保持原样。大备份按词条批次与单张图片处理，避免单次请求过大。
6. Cloudflare PNG 解码改为公共、受限 zlib 接口，解决真实上传兼容故障；原图逐像素检查通过。
7. 图片在写入前原子预留唯一内容的存储预算；队列满时拒绝上传，更换昵称不能绕过来源投稿限额。
8. 首次授权自动启用，重启后继续生效；撤销与恢复是共享权限操作，本机完整功能始终可用。

## 权限、数据与运转

管理凭证留在本机服务器，公共前端不含管理密钥。浏览下载免登录，投稿只填昵称；投稿凭证使用 HttpOnly Cookie，伙伴可以下载后恢复自己的投稿与反馈。预审授权按词条、素材类别限制，不能擅自发布、创建管理授权或改变范围。

共享更新带当前修订，冲突整批回滚；同名不同定义可共存。原图、独立“我的”、项目快照、共享修订分别保存，资料更新不会自动改旧卡组。资料删除进入回收站，历史回滚产生新修订。

开放投稿仍有保护：单人每日 40 项、同来源每日 200 项、待审核最多 500 项；共享图片最多 15MB / 420 万像素，唯一二进制总预算 512MB。PNG/JPG/WebP 真实解码重编码，SVG、动画与伪装内容拒绝。私人原图单张最多 40MB。预算耗尽时拒绝新增共享图片，本机原图继续保留。

备份包含本机原图、共享元数据、版本、审核和有权访问的图片，不导出原始管理凭证。网络无法访问共享服务时只能保证本机备份，ZIP 中 README 会写明共享是否完整。默认恢复增量收录到“我的”；共享历史及审核记录作为备份存档，不自动覆盖线上数据库。在线已有内容可在历史页回滚。
