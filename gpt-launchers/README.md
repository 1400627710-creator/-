# 卡递启动器与车卡机启动器

今后统一使用以下中文名称：

| 工具 | 启动器 |
| --- | --- |
| 卡递：本地卡牌工作台 | `卡递启动器.bat` |
| 车卡机：原小说档案工具 | `车卡机启动器.bat` |

## 使用方法

1. 下载完整仓库压缩包并选择“全部解压”。
2. 保持 `gpt-launchers` 与 `gpt-baseline-1.0` 两个文件夹位于同一目录。
3. 进入 `gpt-launchers`，双击所需工具的中文启动器。

启动器通过系统默认浏览器打开对应本地 HTML 页面，无需启动 Node 服务。首次使用或更换文件位置时，按工具中的备份与导入功能恢复已有资料。

## 验证范围

已核对两个入口分别指向卡递和车卡机，目标文件存在，Windows 批处理使用 UTF-8 和 CRLF 换行。Windows 双击启动尚未实测。

原始 1.0 归档保留于 `gpt-baseline-1.0`。后续界面、启动入口与交付说明统一使用“卡递”和“车卡机”。
